# 示波器功能实现说明

## 目标

上位机通过 USB-RS485 接收固件输出的 V2 多模式波形数据，按帧内模式和通道 ID 实时显示 1～4 条曲线。支持三相电流、DQ 电流指令/反馈以及混合单位自定义通道。没有硬件时可使用内置三相正弦源验证同一条显示链路。

## 协议实现

协议入口位于 `servo_transport.py`，与 `pc_waveform_protocol.md` 保持一致：

- 帧头 `A5 5A`，协议版本固定为 2；
- 通道数为 1～4，帧长动态计算为 `12 + 5*N`，即 17～32 字节；
- 小端解析 16 位帧序号、32 位 ADC 序号、N 个通道 ID 和 N 个有符号 `int32`；
- CRC8 使用多项式 `0x07`，覆盖 CRC 之前的完整变长帧；
- 所有整数除以 1000 恢复工程值，再按通道 ID 映射名称和 A、pu、rad、V 等单位。

`WaveformParser.feed()` 接受任意长度字节块，可处理不同长度帧粘连、半帧和错位。解析器取得前 5 字节后先验证版本、模式与通道数，再计算本帧长度；CRC、模式、数量或通道 ID 错误时只丢弃一个字节后重新搜索。模式切换时每帧独立解码，不依赖上一帧的结构。

## 数据源与线程

`SerialWaveformSource` 在后台线程读取串口（921600、8-N-1），解析后的帧写入有限队列，Qt 主线程通过 `drain()` 批量取走，避免串口阻塞界面。

`SineWaveformSource` 生成 1 kHz、1 Hz 的平衡三相电流，并先编码成正式 V2 模式 1、通道 `{1,2,3}` 的 27 字节帧，再交给生产解析器解码，因此可以同时验证生成、CRC、变长解析和显示链路。

## 波形显示

`servo_ui.py` 中 `ScopeChart` 提供四个显示槽。槽位不是固定信号，而是按每帧的通道 ID 动态绑定。例如：

| 模式 | 显示内容 |
|---|---|
| 电压开环 | U/V/W 三相电流，单位 A |
| 电流开环 | D 指令、D 反馈、Q 指令、Q 反馈，单位 A |
| 自定义 | 1～4 个任意合法通道，按 ID 显示各自工程单位 |

进入 RS485 或内置正弦数据源后，界面会在帧模式或 ID 列表变化时清空旧曲线并重新绑定，避免将队列中残留的旧模式数据标成新通道。界面同时显示当前模式、有效帧数、CRC 错误、协议错误、帧序号跳变、ADC 序号异常和队列丢弃数；完整序号与重同步信息保留在链路统计提示中。

鼠标进入绘图区后，示波器把横坐标映射到最近采样点，绘制竖直游标，并按通道 ID 显示所有可见通道的数值与单位；鼠标离开后提示自动消失。鼠标滚轮可缩放共享纵轴，量程限制在 ±0.1 至 ±1000；只有全部可见曲线单位一致时，纵轴才显示该单位，混合单位模式以悬停提示为准。

## 窗口与主题

启动时根据当前屏幕可用面积计算接近全屏（约为此前半屏面积的 2 倍）的 16:10 固定窗口，禁用最大化和尺寸拖拽。内部设计画布同为 16:10，不会再因比例不一致产生上下留白。默认应用亮色主题，标题栏按钮仍可切换深色主题。

## 测试

运行：

```powershell
python -m unittest discover -s tests -v
```

`tests/test_servo_transport.py` 覆盖 17/22/27/32 字节帧、四种模式字段、14 个通道定义、混合单位、自定义通道、CRC、任意分块、不同长度粘包、坏帧重同步、非法版本/模式/数量/ID、序号回卷、ADC 连续性和 V2 三相演示源。
