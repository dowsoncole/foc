# 示波器功能实现说明

## 目标

上位机通过 USB-RS485 接收固件输出的 V2 多模式波形数据，按帧内模式和通道 ID 实时显示 1～4 条曲线。支持三相电流、DQ 电流指令/反馈以及混合单位自定义通道。没有硬件时可使用内置三相正弦源验证同一条显示链路。

## 协议实现

协议入口位于 `servo_transport.py`，与 `pc_waveform_protocol.md` 保持一致：

- 帧头 `A5 5A`，协议版本固定为 2；
- 通道数为 1～4，帧长动态计算为 `12 + 5*N`，即 17～32 字节；
- 小端解析 16 位帧序号、32 位 ADC 序号、N 个通道 ID 和 N 个有符号 `int32`；
- CRC8 使用多项式 `0x07`，覆盖 CRC 之前的完整变长帧；
- 所有整数除以 1000 恢复工程值，再按通道 ID 映射名称和 A、pu、rad、V 等单位。

`WaveformParser.feed()` 接受任意长度字节块，可处理不同长度帧粘连、半帧和错位。解析器取得前 5 字节后先验证版本、模式与通道数，再计算本帧长度；CRC、模式、数量或通道 ID 错误时只丢弃一个字节后重新搜索。模式切换时每帧独立解码，不依赖上一帧的结构。

## 数据源与线程

`SerialWaveformSource` 在后台线程读取串口（921600、8-N-1），解析后的帧写入有限队列，Qt 主线程通过 `drain()` 批量取走，避免串口阻塞界面。

`SineWaveformSource` 生成 1 kHz、1 Hz 的平衡三相电流，并先编码成正式 V2 模式 1、通道 `{1,2,3}` 的 27 字节帧，再交给生产解析器解码，因此可以同时验证生成、CRC、变长解析和显示链路。

## 波形显示

`servo_ui.py` 中 `ScopeChart` 提供四个显示槽。槽位不是固定信号，而是按每帧的通道 ID 动态绑定。例如：

| 模式 | 显示内容 |
|---|---|
| 电压开环 | U/V/W 三相电流，单位 A |
| 电流开环 | D 指令、D 反馈、Q 指令、Q 反馈，单位 A |
| 自定义 | 1～4 个任意合法通道，按 ID 显示各自工程单位 |

进入 RS485 或内置正弦数据源后，界面会在帧模式或 ID 列表变化时清空旧曲线并重新绑定，避免将队列中残留的旧模式数据标成新通道。界面同时显示当前模式、有效帧数、CRC 错误、协议错误、帧序号跳变、ADC 序号异常和队列丢弃数；完整序号与重同步信息保留在链路统计提示中。

鼠标进入绘图区后，示波器把横坐标映射到最近采样点，绘制竖直游标，并按通道 ID 显示所有可见通道的数值与单位；鼠标离开后提示自动消失。普通鼠标滚轮缩放共享纵轴，量程限制在 ±0.1 至 ±1e9；只有全部可见曲线单位一致时，纵轴才显示该单位，混合单位模式以悬停提示为准。

横轴使用数据源采样率换算成真实毫秒：最新采样点定义为 `0 ms`，历史点显示为负时间。按住空格并滚动鼠标滚轮可改变可见采样数量，从而缩放时序范围；按住鼠标左键左右拖动可改变相对最新点的历史偏移，偏移和缩放均限制在当前缓存内。

双击嵌入式波形图会打开 `ScopePopup` 独立窗口。弹窗直接读取主图的实时数据、通道名称、单位、显隐状态与采样率，但维护独立的纵轴量程、时间窗口和历史偏移，不会启动第二个串口读取线程。

独立窗口使用原生系统标题栏，标题为“实时波形 - 独立视图”，并提供标准最小化、最大化和关闭按钮。目标尺寸为 2400×1520；若屏幕可用区域不足，则使用可用宽高的 96% 并居中。波形右上角悬浮“操作帮助”按钮，白色帮助面板默认展开并逐行显示快捷键。按钮和面板都是波形子控件，不参与布局，因此不会压缩绘图区或改变时间轴范围；面板在定位时提升到子控件顶层，不会被图表 `paintEvent` 绘制的悬停数值覆盖。波形内部不再提供重复的关闭按钮，统一使用系统标题栏关闭。

坐标布局为边界安全设计：底部为横轴刻度和 `TIME / ms` 分别预留行高；首尾刻度分别向内对齐；纵轴边距根据量程和单位文字宽度动态变化。悬停框按内容计算宽度，在右边空间不足时自动移到游标左侧，并始终钳制在绘图区内。

峰值、谷值、均方根和频率统计由波形上方的“统计通道”下拉框指定。V2 帧模式或通道 ID 列表变化时，下拉框会按新通道重建；统计值使用所选通道对应的工程单位。

主界面的“实时波形”和 `V2 MULTI-CHANNEL SCOPE` 是波形卡片外部的独立标题行；带边框卡片内部仅包含 `ScopeChart`，避免标题占用绘图区的线性显示空间。卡片使用 1 px 内沿保留边线，`ScopeChart` 背景按 6 px 圆角裁剪并贴合内框，使绘图区与背景框成为统一视觉组件。

数据源列表只提供 `RS485 串口` 和 `内置正弦演示`。未打开 RS485、也未显式选择内置正弦源时，不产生任何隐式仿真波形，采集按钮保持不可用。

示波器定时刷新具有独立异常边界。数据源读取、帧转换或统计更新失败时，界面停止采样定时器并关闭异常数据源，在状态栏显示故障，同时将 traceback 写入 `logs/servo_crash.log`；应用不会因 Qt 定时回调中的 Python 异常直接退出。应用入口同时启用 `faulthandler` 和全局异常钩子，用于记录更底层的原生故障及未捕获异常。

## 窗口与主题

空格＋滚轮保持鼠标下的采样点在原横向位置，窗口边界限制在缓存内（整数索引有舍入误差）。实时数据仍持续推进。

“接收周期”控制上位机批量读取缓存的定时器，默认 33 ms，连接时保留选择。协议默认输出率 1 kHz，即每通道每 1 ms 一个点；10 ms 接收周期通常批量读取约 10 个点，而不是改变板端采样率。协议源 ADC 采样率为 20 kHz。

示波器标题与统计通道选择使用同一行。页布局与波形外框传播最小尺寸，空间不足时滚动，不裁切图表负轴或横轴。通道选择按内容调整宽度，曲线填充与选择通道同步。帮助为独立左对齐双列。

统计文本以 5 Hz 更新；密集曲线按分桶峰谷绘制，最多约 800 点/通道，完整原始缓存仍用于统计及悬停。纵轴可缩放至 ±1e9，超量程显示提示；不会因异常大电流数值自行修改协议解码。

启动时根据当前屏幕可用面积计算接近全屏（约为此前半屏面积的 2 倍）的 16:10 固定窗口，禁用最大化和尺寸拖拽。内部设计画布同为 16:10，不会再因比例不一致产生上下留白。默认应用亮色主题，标题栏按钮仍可切换深色主题。

## 测试

运行：

```powershell
python -m unittest discover -s tests -v
```

`tests/test_servo_transport.py` 覆盖 17/22/27/32 字节帧、四种模式字段、14 个通道定义、混合单位、自定义通道、CRC、任意分块、不同长度粘包、坏帧重同步、非法版本/模式/数量/ID、序号回卷、ADC 连续性和 V2 三相演示源。

`tests/test_scope_ui.py` 使用 Qt 离屏模式验证时间缩放和平移边界、独立窗口共享数据但保持独立视图，以及统计值确实来自用户选择的通道。
