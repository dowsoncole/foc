# 上位机波形协议与模式选择说明（V2）

本文件同步自固件工程：

`G431_base_code/software/servo_v1/MDK-ARM/docs/pc_waveform_protocol.md`

## 1. 支持模式

| 模式 | 值 | 默认曲线 |
|---|---:|---|
| 关闭 | 0 | 不发送新帧 |
| 电压开环 | 1 | U、V、W 三相电流 |
| 电流开环 | 2 | D 指令、D 反馈、Q 指令、Q 反馈 |
| 自定义 | 3 | 用户指定的 1～4 个通道 |

波形模式和 FOC 控制模式相互独立。PC 必须读取每一帧携带的模式与通道 ID，不得根据当前控制模式或通道位置猜测曲线含义。

## 2. 通道 ID 与工程单位

| ID | 信号 | 帧整数单位 | PC 显示单位 |
|---:|---|---|---|
| 1 | U 相电流 | mA | A |
| 2 | V 相电流 | mA | A |
| 3 | W 相电流 | mA | A |
| 4 | D 电流指令 | mA | A |
| 5 | D 电流反馈 | mA | A |
| 6 | Q 电流指令 | mA | A |
| 7 | Q 电流反馈 | mA | A |
| 8 | D 电压输出 | 0.001 pu | pu |
| 9 | Q 电压输出 | 0.001 pu | pu |
| 10 | U 相占空比 | 0.001 | 无单位 |
| 11 | V 相占空比 | 0.001 | 无单位 |
| 12 | W 相占空比 | 0.001 | 无单位 |
| 13 | 电角度 | mrad | rad |
| 14 | 直流母线电压 | mV | V |

所有 `int32` 数值均按“原始工程值 × 1000”编码，PC 解码后统一除以 1000，再根据通道 ID 选择名称和单位。

## 3. 串口参数

| 参数 | 配置 |
|---|---|
| 接口 | USART1 / RS485 |
| 波特率 | 921600 |
| 格式 | 8-N-1，无硬件流控 |
| 字节序 | 小端序 |
| 源采样率 | 20 kHz |
| 默认输出率 | 1 kHz |
| 协议版本 | 2 |

## 4. V2 可变长度帧

通道数量 `N` 为 1～4：

```text
frame_length = 12 + 5 * N
```

| 偏移 | 长度 | 字段 |
|---:|---:|---|
| 0 | 2 | 帧头 `A5 5A` |
| 2 | 1 | 版本，固定为 2 |
| 3 | 1 | 波形模式 |
| 4 | 1 | 通道数量 N |
| 5 | 2 | 帧序号，小端 `uint16` |
| 7 | 4 | ADC 源采样序号，小端 `uint32` |
| 11 | N | N 个通道 ID |
| 11+N | 4×N | N 个小端 `int32` 数值，与 ID 顺序一致 |
| 最后 1 字节 | 1 | CRC8 |

常见帧长：

- 1 通道：17 字节；
- 2 通道：22 字节；
- 三相电流：27 字节；
- DQ 指令/反馈：32 字节。

## 5. CRC8

CRC 初值为 0，多项式为 `0x07`，不反转输入和输出，无最终异或。校验范围从帧头开始，到最后一个数据字节结束，不包含 CRC 字节。

```python
def crc8(data: bytes) -> int:
    crc = 0
    for value in data:
        crc ^= value
        for _ in range(8):
            crc = (((crc << 1) ^ 0x07) if crc & 0x80 else crc << 1) & 0xff
    return crc
```

## 6. 接收与重同步

串口读取结果可能是半帧、多帧粘连或从帧中间开始。PC 接收端必须：

1. 持续把字节追加到缓存；
2. 搜索 `A5 5A`，保留块末尾单个 `A5`；
3. 缓存至少 5 字节后校验版本、模式和通道数量；
4. 根据 `12 + 5*N` 等待完整帧；
5. 验证 CRC 和通道 ID；
6. 成功后消费完整帧，失败时只丢弃一个字节并重新搜索。

模式切换后，固件队列可能短暂保留旧模式帧。PC 应按每一帧自己的模式、通道数量和通道 ID 解析；当通道签名变化时重新绑定曲线，不能假设第一个通道固定是 U 相电流。

## 7. 连续性检查

- 帧序号按 16 位无符号数自然回卷，正常增量为 1；
- ADC 序号按 32 位无符号数自然回卷；
- 默认 20 kHz 源采样降采样到 1 kHz 时，相邻 ADC 序号通常相差 20。
