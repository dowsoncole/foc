# AUUSN Motor Studio

基于 PyQt5 的伺服驱动器调试上位机。界面参考 AUUSN 伺服调试软件的工作流重新设计，采用现代无边框桌面窗口、红色阳极氧化金属与磨砂玻璃风格，以及高密度信息布局。

> 电机控制部分仍为安全仿真程序，不会连接或控制真实电机。`servo_v1` 固件的 RS485 波形流已可在“实时示波器”页面真实接收并显示；USB、CANopen、EtherCAT 控制通道仍需接入对应驱动和协议实现。

## 功能

- 驱动器状态总览、目标/反馈/误差轨迹跟随、位置/速度/电流模式与使能控制
- 四通道实时示波器、通道显隐和统计数据；鼠标悬停可查看最近采样点的各通道精确幅值
- 真实 RS485 波形采集：接收 `servo_v1` 固件 V2 可变长度帧（1～4 通道、17～32 字节、921600 8-N-1），按帧内模式与通道 ID 动态显示三相电流、DQ 指令/反馈或自定义信号，并自动匹配 A、pu、rad、V 等单位；后台线程解析、CRC8 校验与自动重同步，另内置 V2 三相正弦源可无硬件验证显示链路
- 参数表搜索、分组、编辑、读取、写入、默认值恢复和 EEPROM 保存
- 参数 JSON 导入与导出
- 六路 DI 原始电平模拟、0-100 ms 输入滤波、状态历史、功能映射，以及 DO 映射和手动测试
- USB、RS485、CANopen、EtherCAT 连接配置
- CiA 402 / EtherCAT PDO 映射展示与校验
- 故障历史、故障复位、电机与编码器快速配置向导
- 本地固件升级流程模拟
- 基于 `1440 x 900`（16:10）设计基准面的全界面等比缩放；启动窗口面积约为此前半屏窗口的 2 倍，不提供最大化或拖拽缩放
- 拉丝银红金属亮色主题为默认主题，并可通过标题栏的 `DARK / LIGHT` 按钮即时切换
- 可选的全窗环境特效层，默认关闭以保证高分辨率窗口流畅度，需要时可通过 `FX` 开关启用
- 页面切换使用不改变透明度的轻量方向横移，避免无边框透明窗口切页时出现闪烁或透底
- 留白区域使用五套状态驱动动画：电机图形跟随实际转速和方向、数字脉冲显示 DI 历史、逻辑矩阵对应 DO 测试状态、通讯拓扑仅在连接时传输、芯片写入严格跟随升级进度
- 使用统一渲染时钟调度可见动画，静止组件不重绘，示波器仅在新采样到达时刷新；窗口最小化时自动暂停视觉刷新
- 总览不再重复绘制示波器波形，改用低开销轨迹跟随视图；DI 时序图仅显示滤波后的六路真实业务状态
- DI 的 `LOW / HIGH` 测试电平经过可调防抖滤波后驱动伺服使能、故障复位、正反向限位、模式切换和转矩限制等模拟逻辑
- 位置、速度和电流模式使用独立目标单位与范围，速度命令支持正反转并受速度上限约束
- 示波器触发、总线配置、PDO 校验、I/O 映射、故障注入、配置向导和固件升级均提供可操作的模拟演示流程

## 工程结构

- `servo_core.py`：纯仿真模型、数值约束与参数目录，不依赖界面
- `servo_transport.py`：真实 RS485 波形传输层，包含帧解析、CRC8 校验、串口读取线程与内置正弦演示源，不依赖界面
- `servo_animations.py`：适配透明无边框窗口的纯位移页面转场
- `servo_visuals.py`：动态技术插图组件
- `servo_ui.py`：窗口、页面组件、主题及事件编排
- `main.py`：程序入口
- `tests/`：核心模型与数据完整性测试

串口读写全部收敛在 `servo_transport.py`，页面组件只调用统一的数据源接口。后续接入 USB、CAN 或 EtherCAT 时，请在同一层新增对应的传输实现，不要把硬件读写直接写入页面组件。

## 测试文件

`tests/test_main.py` 保护不依赖界面的核心行为：

- 验证 `clamp` 不会产生超出安全上下限的数值
- 验证参数索引和子索引组合没有重复，防止写错对象字典地址
- 验证设备未连接时电机不会运动
- 验证连接并使能后模型会向目标位置运动
- 验证速度模式能跟踪正负 rpm 命令且不会突破速度上限
- 验证长时间运行后模拟温度仍被限制在定义范围内

这些测试直接导入 `servo_core.py`，因此无需启动窗口，运行速度快，也不会受到主题或动画调整影响。

`tests/test_servo_transport.py` 保护 RS485 波形链路，同样不依赖界面和硬件：

- 验证 V2 的 1～4 通道对应 17/22/27/32 字节帧，CRC8 与固件使用同一多项式
- 验证三相、DQ 与自定义混合单位通道按 ID 正确解析和绑定
- 验证不同长度连续帧、跨块拆分、字节错位、CRC 损坏和块尾半个帧头都能正确解析或重同步
- 验证内置 V2 三相正弦源每秒产生一个完整周期、帧序号在 16 位处回卷
- 验证波特率标签解析与频率估计的边界行为

## 设计来源

界面不是消费类仪表盘，而是面向重复操作的工业工作台。视觉与交互主要参考 Microsoft Fluent 的双层窗口结构和左侧导航、iF 获奖工业 HMI 的任务分层、Red Dot SCADAMaster 的模块化设备配置，以及 TradingView 一类专业工具的高密度图表与命令栏。迁移时保留了 AUUSN 原软件的参数表、示波器、通讯、I/O 和诊断工作流，同时增加全局设备状态、导航任务编号、参数上下文说明、只读监视值和窄窗口滚动。

## 运行

需要 Python 3.10 或更高版本。在项目目录的 PowerShell 中执行：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python -m pip install -e ".[serial]"   # 需要真实 RS485 波形采集时执行
python main.py
```

不装 `pyserial` 也能正常启动，此时“数据源”仍可使用仿真模型与内置正弦演示，选择 RS485 串口会提示缺少依赖。

运行测试：

```powershell
python -m unittest discover -s tests -v
```

## 使用流程

1. 在“通讯配置”选择协议、接口、波特率和节点 ID，然后点击“连接驱动器”。
2. 返回“总览监控”，选择工作模式、目标值和速度限制，再开启伺服使能。
3. 在“实时示波器”观察位置、速度、电流和位置误差信号。
4. 需要看固件真实波形时，在“实时示波器”页面把“数据源”切到 `RS485 串口`，点“刷新”选中适配器的 COM 口，确认波特率为 `921600 bps`，再点“打开串口”。曲线会按 V2 帧中的模式和通道 ID 自动切换名称、数量与单位；鼠标悬停可查看精确值。“链路统计”会显示模式、帧数、校验错误、序号异常和丢弃计数。约 1 秒收不到数据会提示检查接线；切回“仿真模型”即恢复原有演示。
5. 在“参数管理”编辑当前值，写入缓存后关闭使能，再保存 EEPROM。
6. 在“数字 I/O”设置 DI 功能和滤波时间，再切换每路 `LOW / HIGH` 电平；状态灯、六路时序图和对应控制逻辑会使用同一份滤波后数据。
7. 点击标题栏右侧的 `LIGHT` 或 `DARK` 按钮切换界面风格。
8. 使用 `FX ON / FX OFF` 开关控制全窗科技特效；特效层不会阻挡鼠标操作。

## Windows 打包

```powershell
python -m pip install ".[build]"
python -m PyInstaller --noconfirm --clean --windowed --name AUUSN-Motor-Studio main.py
```

正式接入硬件前，应补充协议适配器、安全联锁、急停、操作权限、审计日志和设备端写入确认机制。
