# ADC 采样配置审查报告

审查对象：`software/servo_v1` 的 OPAMP1/OPAMP3 + ADC1 注入组电流采样配置。

审查方式：静态检查初始化代码、MSP、TIM1 触发链、主循环和 FOC 接口；未进行示波器、实机采样或满负载测试。

## 结论

配置层的通道、时钟、注入序列和校准调用基本完整，但当前固件尚未形成可用的 ADC 数据链路，不能据此宣称“电流采样已上线”。后续真正接入 FOC 前，必须先解决采样时序和两路通道对应相别的问题。

## 发现项

| 编号 | 严重度 | 发现 | 证据 | 影响 |
|---|---|---|---|---|
| ADC-01 | 高 | 当前只初始化/校准 ADC 和运放，没有启动运放、注入转换或数据消费 | `main.c:168-179` 调用 `MX_OPAMP*_Init()`、`MX_ADC1_Init(1U)`；代码中没有 `HAL_OPAMP_Start()`、`HAL_ADCEx_InjectedStart*()`、`HAL_ADCEx_InjectedGetValue()` 或 JDR 读取 | 当前不会产生有效电流采样；`ia_offsets`/`ib_offsets` 也不会被填充 |
| ADC-02 | 高 | 16 倍过采样造成注入序列约 11.43 µs，TIM1_CH4 仅提前更新事件 1 µs | `adc1_current_sampling.c:96-103`、`181-188`；`tim1_pwm.h:65-67` | 转换跨越 PWM 更新事件；在 CC4 入口读数据会得到上一轮或滞后数据，采样窗口还可能混入开关噪声 |
| ADC-03 | 高 | 没有完整的结果处理链路：无偏置标定、无累加值换算、无 FOC feedback 接线 | `adc1_current_sampling.c:20-24`；根目录 README 的 FOC 接口仍标为未实现 | 即使硬件开始转换，FOC 仍拿不到安培值；直接把 JDR 当 12 位码会产生 16 倍量纲错误 |
| ADC-04 | 高 | ADC1_IN3 与 ADC1_IN12 各自对应哪一相尚未从现有资料确认 | `adc1_current_sampling.c:209-222` 只确认 rank/引脚；项目 README 的待核对项 J 记录原理图线索冲突 | 相别接错会使 Clarke/Park 变换和电流环方向错误，属于功能性风险 |
| ADC-05 | 中 | `DataAlign = ADC_DATAALIGN_LEFT` 在注入过采样开启时被硬件忽略 | `adc1_current_sampling.c:125-128` | 配置本身不一定错误，但业务层必须按右对齐的 16 位累加值处理，并除以 16；左对齐假设会导致结果错误 |
| ADC-06 | 中 | `ADC_OVR_DATA_PRESERVED` 会保留旧结果，当前没有超时/溢出监控 | `adc1_current_sampling.c:138-140` | 若实时消费者迟到或转换重叠，系统可能静默使用旧电流值；应增加 JEOC/OVR 状态检查和故障策略 |
| ADC-07 | 中 | 触发源只在初始化时决定，没有安全的运行时切换接口 | `MX_ADC1_Init(uint8_t software_trigger_flag)`，`adc1_current_sampling.c:190-204` | 标定阶段软件触发、运行阶段 TIM1_CH4 触发之间无法由业务层安全切换，重配时还需保证 ADC 不在转换 |
| ADC-08 | 低 | 2.5 cycles 为最短采样时间，外部 RC 的建立时间尚未由参数或实测证明 | `adc1_current_sampling.c:186-188` | 运放输出虽低阻，但 RC 截止频率、开关噪声和 ADC 采样电容共同决定最终误差；需要示波器/静态电压误差验证 |

## 已确认的合理配置

- ADC1 独立模式，注入组两通道，rank 1 为 ADC1_IN3/PA2，rank 2 为 ADC1_IN12/PB1，和当前“两相采样”的算法需求一致。
- ADC 同步时钟为 168 MHz / 4 = 42 MHz，处于 STM32G431 ADC 允许范围内。
- 单端校准前显式 `HAL_ADC_Stop()`，初始化顺序为运放后 ADC，顺序合理。
- 注入组使用序列级 EOC、关闭自动注入和上下文队列，适合固定触发序列；但仍需要补齐启动、结果读取和异常处理。
- PA2/PB1 走外部 ADC 引脚，OPAMP 输出引脚配置为模拟模式，符合代码所述的外部 RC 路径设计。

## 建议整改顺序

1. 先用硬件或完整原理图确认 rank 1/rank 2 的实际相别，并固化 `phase_a/phase_b` 映射。
2. 决定时序方案：优先实测 FOC 单次执行时间和开关噪声；候选方案包括降低过采样倍率、把触发提前量扩大到大于 11.43 µs，或接受明确的一周期延迟。
3. 增加采样业务层：运放启动、ADC 注入启动、JEOC/OVR 处理、JDR 读取、16 倍累加值缩放、零电流多次平均标定和安培换算。
4. 设计标定到运行的触发切换 API，切换前停止或确认 ADC 空闲，禁止上层直接改 JSQR。
5. 用示波器同时观察 TIM1_CH4、ADC 转换完成时刻、PWM 边沿和运放输出；再用已知电流验证零点、增益、相别和满量程裕量。

## 审查边界

本报告没有修改源码，也没有替代硬件验证。当前工程 README 已明确将电流采样标为“配置层完成、业务层未实现”；因此本次审查结论是“配置骨架基本成立，但尚未达到可交付的实时电流采样状态”。
