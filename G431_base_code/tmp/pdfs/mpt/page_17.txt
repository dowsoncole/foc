BUS (High speed bus) protocol interface
Electrical connection diagram:
Encoder Controller
The interface uses a two-wire differential A/B signal configuration. Termination resistors are required on
both lines. The encoder-side termination resistor is integrated inside the encoder, and a termination
resistor should be added on the controller side. The protocol uses RS485 electrical signaling and UART data format, with a default baud rate of 2.5 Mbps. The interface receives a 1-byte command request, returns the corresponding encoder data according to
the request, and appends a CRC-8 (x⁸ + 1) checksum at the end of the data for verification. Version Selection:
