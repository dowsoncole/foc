(some core versions don’t support unaligned data read; Even with support for unaligned reads, the kernel consumes
more concatenation time). For the reception of BISS-C, the first byte received will be a placeholder byte with ACK, and the position data starts
from the second byte, to read data and calculate CRC quickly, it is necessary to calculate CRC from the address

} receiveBuffer;
