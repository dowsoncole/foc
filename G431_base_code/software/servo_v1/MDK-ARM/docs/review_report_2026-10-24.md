### [P2] 编码器偏移归一化可能在关闭中断期间无限循环

证据：Modules/Encoder/Src/encoder.c:64–74、308–325。
Encoder_ConfigureMotor 仅要求偏移为有限浮点数；随后关闭中断并调用 Encoder_WrapAngle。后者反复加减 2π，没有幅度限制或迭代上限。
对合法有限输入 1e10f，float32 精度下减去 2π 后仍等于原值，while 条件永远不变。负的大幅度输入有同类问题。即使数值较小且能收敛，执行时间也随输入幅度增长，并占用全局关中断区间。

验证：用 Python struct 的 float32 舍入模拟单步，得到 angle=10000000000.0，angle-minus-2pi=10000000000.0，unchanged=True；未在目标板调用该危险输入。
影响条件：上层调用配置接口并传入大幅度偏移。未发现当前 main 直接调用该配置函数，因此不声称默认启动必然卡死；这是公开接口接受的输入范围内的缺陷。
建议：在关中断之前完成参数校验及有界时间的归一化，例如明确限制允许幅度，或使用合适的余数计算并验证结果；临界区只负责发布配置和重置状态。增加正负大数、边界 2π、NaN/Inf 及正常标定值测试。
