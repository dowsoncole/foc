# 电流采样校准启动设计

## 1. 设计目标

本设计用于 STM32G431 的两电阻电流采样方案：PA2/ADC1_IN3 为 U 相，PB1/ADC1_IN12 为 V 相，分流电阻 7 mΩ，运放增益 6.1，ADC 注入组 16 倍过采样，采样频率 20 kHz。

校准要求是下管导通后等待 10 ms，再在 1 ms 内按 FOC 采样周期采集 20 个样本。校准过程不能暂停 TIM1，也不能依赖 FOC 产生 ADC 触发。

## 2. 互相等待问题

错误的启动逻辑如下：

```text
等待校准完成 → 启动 TIM1 → TIM1_CH4 触发 ADC → 得到 ADC 样本 → 校准完成
```

这会形成闭环：校准需要 TIM1_CH4，TIM1 又等待校准完成后才启动，因此 ADC 没有样本，校准最终超时。

## 3. 解耦后的硬件关系

本设计把“采样时基”和“功率输出”分开：

```text
TIM1 计数器 → TIM1_CH4 比较事件 → ADC 注入触发 → JEOS 中断 → JDR1/JDR2

MOE 功率输出门 → 决定 PWM 是否真正到达栅极驱动器
```

TIM1 计数器和 CH4 在校准前就启动；MOE 只控制功率级输出是否放行。即使 MOE 为 0，TIM1 仍可以运行，CH4 仍可以作为 ADC 的内部触发源。

## 4. 正确启动顺序

```text
MX_TIM1_Init()
    ├─ 配置中心对齐 PWM、CH4 比较值
    ├─ 启动 TIM1 计数器和 CH4
    └─ 保持 MOE=0
        ↓
MX_OPAMP1_Init() / MX_OPAMP3_Init()
        ↓
MX_ADC1_Init(0U)
    └─ 注入组选择 TIM1_CH4 上升沿
        ↓
CurrentSampling_Start()
    ├─ 启动 OPAMP1/OPAMP3
    ├─ 启动 ADC 注入组 JEOS 中断
    ├─ 检查 ADC1->CR.ADEn = 1
    └─ 检查 ADC1->IER.JEOSIE = 1
        ↓
确认驱动器 READY
        ↓
CurrentSampling_RequestCalibration()
    └─ 状态变为 SETTLING
        ↓
默认保持 MOE=0
    └─ 等待硬件确认后再选择是否进入下管实验模式
```

请求校准必须在进入 `SETTLING` 后执行。当前工程默认保持 `MOE=0`，这样 ADC 仍然由 TIM1_CH4 触发，但不会因下管导通触发驱动器 VDS 保护。只有完成栅极极性、死区和母线电流测量后，才可以打开 `CURRENT_SAMPLING_ENABLE_LOW_SIDE_CALIBRATION` 进行下管实验。

## 5. 校准状态机

### 5.1 `SETTLING`

当前默认开关 `CURRENT_SAMPLING_ENABLE_LOW_SIDE_CALIBRATION = 0U`，因此此状态下
MOE 仍关闭，ADC 只验证采样链是否能持续产生数据；样本只更新实时原始值，不参与平均，
也不调用 FOC。若经过硬件确认后启用下管实验，必须先以三相中性 CCR 打开 MOE，等待
`TIM1_PWM_MOE_SETTLE_MS`，再把 CCR 改为 duty=0，随后才进入有效校准窗口。
SETTLING 的 10 ms 用于等待模拟链和功率级稳定。

### 5.2 `COLLECTING`

进入采样窗口后，ADC 完成回调读取：

```c
ADC1->JDR1  /* U 相，16 倍累加码 */
ADC1->JDR2  /* V 相，16 倍累加码 */
```

20 kHz 采样频率在 1 ms 内得到 20 个样本。校准累加使用 64 位变量，避免 16 倍过采样累加时溢出。

### 5.3 `DONE`

完成平均后保存：

```text
offset_u = calibration_sum_u / calibration_sample_count
offset_v = calibration_sum_v / calibration_sample_count
```

主循环随后恢复三相 50% 中性点，释放正常 PWM 输出，并启动 FOC。若需要验证下管校准，必须先完成本文第 8 节的硬件测量。

### 5.4 `ERROR`

如果 1 ms 窗口结束时没有收到任何 ADC 样本，状态进入 `CURRENT_SAMPLING_CAL_ERROR`，同时保持 MOE 关闭。

## 6. FOC 与校准的边界

ADC 完成回调链路如下：

```text
TIM1_CH4 → ADC 注入序列 → ADC1_2_IRQHandler()
         → HAL_ADC_IRQHandler(&hadc1)
         → HAL_ADCEx_InjectedConvCpltCallback()
         → 读取 JDR1/JDR2、更新 sample_sequence
```

状态为 `SETTLING` 或 `COLLECTING` 时，FOC 回调被屏蔽；ADC 和 TIM1 不停止。校准完成后，ADC 完成回调才调用已注册的 FOC 回调。

## 7. 为什么不会互相等待

依赖关系被拆成两条独立链路：

```text
采样链：TIM1 计数器 → CH4 → ADC → JEOS → 原始采样值
控制链：校准完成 → 中性点 → MOE → FOC 输出
```

采样链从初始化阶段就开始工作；控制链只在校准完成后放行。控制链不会反过来决定采样链是否运行，所以不存在“定时器等待校准、校准等待定时器”的环路。

## 8. 调试检查表

| 检查项 | 期望值 | 说明 |
|---|---:|---|
| `TIM1->CR1.CEN` | 1 | TIM1 计数器正在运行 |
| `TIM1->CCER.CC4E` | 1 | CH4 比较通道已使能 |
| `ADC1->CR.ADEn` | 1 | ADC 已使能 |
| `ADC1->IER.JEOSIE` | 1 | 注入序列完成中断已使能 |
| `ADC1->JSQR.JEXTSEL` | TIM1_CH4 | 触发源正确 |
| `ADC1->JSQR.JEXTEN` | 上升沿 | 触发边沿正确 |
| `sample_sequence` | 持续递增 | ADC 完成回调正在执行 |
| `calibration_sample_count` | 最终为 20 | 校准窗口收到完整样本 |
| `calibration_state` | `DONE` | 校准完成 |

如果 `ADEn=0` 或 `JEOSIE=0`，应首先检查 `CurrentSampling_Start()` 的返回值、`hadc1.ErrorCode` 和实际下载的固件版本，此时还没有进入模拟采样误差分析阶段。

还必须确认 ADC12 内核时钟已经选择。STM32G4 的 `ADC12SEL` 复位值是 `NONE`；仅执行 `__HAL_RCC_ADC12_CLK_ENABLE()` 只能打开总线访问，不能提供 ADC 转换时钟。工程在 `SystemClock_Config()` 中选择 `RCC_ADC12CLKSOURCE_SYSCLK`，ADC 配置必须使用 `ADC_CLOCK_ASYNC_DIV4` 得到 42 MHz；SYSCLK 源不能配 `ADC_CLOCK_SYNC_PCLK_DIV4`。若遗漏时钟源或混用同步路径，典型现象是 `ADEN=1、JADSTART=1、JEOSIE=1`，但 `JEOS=0、JDR1/JDR2=0`。

### 8.1 再次打开 MOE 前必须完成的硬件测量

当前工程已经将 `CURRENT_SAMPLING_ENABLE_LOW_SIDE_CALIBRATION` 默认设为 `0U`，因为开启三相下管后实测出现 `STATUS=0x84`，其中 `0x04` 是 `VDS_P` 保护。不要仅通过延长软件等待时间继续尝试。

重新打开实验开关前，请在限流电源和断电状态下完成以下确认：

1. 示波器地线接控制板信号地，分别测量 PE9/PE11/PE13（TIM1_CH1/2/3，高侧 INH）和 PE8/PE10/PE12（TIM1_CH1N/2N/3N，低侧 INL）。
2. 确认 `duty=0` 时高侧信号保持关闭，低侧信号才是有效电平；若电平相反，必须修正 `OCPolarity/OCNPolarity` 或校准模式，不能继续给功率板上电测试。
3. 确认高、低侧切换之间存在死区，且没有同一桥臂上下管同时有效。
4. 先不接电机或使用受控的低压母线，确认打开 MOE 的瞬间母线电流没有异常尖峰。
5. 记录 STSPIN32G4 的 `STATUS`、`NFAULT` 和母线电流；只有没有 `VDS_P`、`THSD`、`VCC_UVLO` 时，才可以把开关宏改为 `1U`。

硬件测量期间保持：

```c
#define CURRENT_SAMPLING_ENABLE_LOW_SIDE_CALIBRATION  0U
```

这样仍能验证 TIM1_CH4、ADC JEOS、`sample_sequence` 和零点校准状态机，不会再次释放功率级。

## 10. 复位瞬间电流尖峰的原因

复位尖峰不是 ADC 数值换算造成的，而是功率输出门和比较寄存器的切换顺序造成的。旧顺序在
`Tim1Pwm_EnableCalibrationLowSide()` 中先把三相 CCR 写成 0，再打开 MOE；这会让驱动器在
刚解除关断、输入级和自举电容尚未稳定时立即看到下管校准波形，可能产生一个非对称脉冲或
VDS/母线电流尖峰。

当前接口已改成：

```text
三相 CCR = 中性点 50%
    -> 打开 MOE
    -> 等待 TIM1_PWM_MOE_SETTLE_MS（当前 10 ms）
    -> CCR 改为 0，进入下管校准
```

工程默认仍为 `CURRENT_SAMPLING_ENABLE_LOW_SIDE_CALIBRATION = 0U`，所以正常复位路径不会
打开 MOE，也不会进入下管校准。只有完成示波器、死区和母线电流确认后，才允许临时改为
`1U` 做硬件实验。

## 9. 相关接口

```c
MX_TIM1_Init();
MX_OPAMP1_Init();
MX_OPAMP3_Init();
MX_ADC1_Init(0U);
CurrentSampling_SetConversionCallback(callback, context);
CurrentSampling_Start();
CurrentSampling_RequestCalibration();
Tim1Pwm_EnableCalibrationLowSide();
CurrentSampling_Service();
CurrentSampling_ReadFeedback_s16(&iu, &iv, &iw);
CurrentSampling_ReadFeedback_A(&iu_a, &iv_a, &iw_a);
```

`CurrentSampling_Service()` 必须在主循环中持续调用；ADC 中断只负责采样快照和固定时间的实时回调，不负责阻塞等待或启动定时器。下管校准实验开关位于 `main.c`：

```c
#define CURRENT_SAMPLING_ENABLE_LOW_SIDE_CALIBRATION  0U
```

该值为 `0U` 时，校准期间 MOE 始终关闭；该值改为 `1U` 前必须确认下管栅极电平、互补波形、死区和母线电流。
