## 一、电流采样模块 —— 已全部处理 ✅

**目标：**

1. 能够正常工作，16 倍过采样，读数范围是 0-65536。【已处理】
2. 业务逻辑层，实现功能：【已处理】

   - a. 零点校准：三相输出全部下管导通时测量到的读数是零点值，读取零点值之前需要等待一个小的时间间隔，因为需要等待电路电流稳定再采样才是准确的，正常读数需要减去零点值。思考我的校准方式是否最优。
   - b. 需要有专门的结构体用于管理电流采样模块的参数，其下有校准结构，转换结构。
   - c. 转换结构需要将 adc 读数转为真实物理量，原理是采样电阻加上运放然后使用 adc 读数。所以需要的参数有采样电阻阻值，运放放大倍数。
   - c. foc 需要的接口有读取当前的 ADC 读数，读取当前的真实电流。
   - d. 校准是应用层来下发指令，思考校准逻辑的实现如何能有效分离 FOC 应用层和电流采样模块。

4. ADC 转换完成后，在 ADC 转换完成中断中执行 FOC 逻辑。【已处理】
