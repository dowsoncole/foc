# 2026-10-28：速度环快速响应整定与时域、频域评估

## 1. 任务与记录原则

目标是让速度环更快跟随转速指令，同时测量超调、稳态波动和频率响应。用户确认电机已固定、轴端可安全旋转、测功机制动已卸载，并允许实机速度响应测试。

本次使用当前工程，不能沿用10月22日MT6835阶段的故障结论或参数。当前转子传感器为MT6701，统一用户入口为`g_user_control`，不是只修改旧`g_speed_run`。原始数据、失败尝试和各版固件均保留；模型预测不冒充实机验收，采样反馈性能也不冒充独立测速计精度。

原始证据目录：`software/control_analysis/results/speed_response_20261028/`。后文数据路径以该目录为基准。

## 3. 先保存原有故障，再恢复测试

连接后，目标板处于停机状态，MOE=0。读到的历史运行记录约为：目标7000 rpm、最后实际7008.33 rpm、运行269.39 s。

| 字段 | 保存值/含义 |
|---|---|
| 用户状态 | state=4、fault=3：后端故障 |
| 速度执行器 | state=4、fault=4：编码器反馈无效 |
| feedback_fault | 0x20：角度跳变不合理，不是0x02 CRC |
| 反馈年龄 | 13972个168 MHz周期，约83.17 μs |
| 诊断累计 | CRC 2次、角度跳变13次、捕获15次 |
| runtime/controller fault | 均为0x06：角度和参考无效 |
| 输出 | TIM1 BDTR=0x02002054，MOE位为0 |

完整二进制见`preflight/`、`preflight_chunked/`、`preflight_verified/`和最终可信的`preflight_100khz/`。这些是不同调试读取尝试，不能把调试读错的数据直接当成Flash损坏。

当前10个载波周期的新鲜度配置在20 kHz下相当于500 μs；源码中“10 kHz时1 ms”的旧注释不能用于当前时间换算。此次保存的83.17 μs并不能解释为超时，主要错误标志是0x20。

保存后才在MOE关闭时复位。通过硬件断点停在`main`入口，把用户和旧速度使能均设为0，再运行初始化，避免下载/复位后的默认上电流程立即产生电机输出。没有直接修改故障位、解除编码器锁存或自动反复启动。

## 4. 调试链路核对

### 4.1 J-Link与调试频率

原ST-Link不在设备列表，`pyocd list`返回J-Link 150710982。以1 MHz SWD读取时出现大块Flash不一致、个别短块重复字以及一次CoreSight识别失败。降低为100 kHz后，原固件全部82336个Flash加载字节与当前AXF逐字节一致，才允许后续RAM写入和运动测试。

不能把SWD的100 kHz与编码器SPI时钟混为一谈：本次降低的是电脑调试连接，不是SPI采样或电流环控制频率。

### 4.2 每次实验前后的门

测量脚本从指定AXF动态解析地址，不沿用10月22日地址。每个新实验先分块读取并比对全部Flash加载字节，包含压缩RW初始化数据。镜像不一致时，在任何RAM写入之前拒绝执行。运动需要显式`--run`，否则只读核对镜像。

每次实验前确认CPU正在运行、MOE关闭、runtime及FOC故障为0。实验后确认记录状态DONE、512点完整、实际锁定PI与请求相同、诊断错误计数没有新增，并再次确认MOE=0。所有异常都停止后续批次，不清故障自动重试。

审计脚本中的`accepted`/“合格记录”只代表数据完整、镜像和保护检查通过，**不代表超调、波动或调节时间达到性能要求**。1000 rpm波动大的记录仍是有效证据，必须纳入性能评价。

新增`Tests/Inc/speed_response_test.h`及`Tests/Src/speed_response_test.inc`，由正式速度执行器装配。`g_speed_response`是开发测试入口，普通运行时保持未请求/完成状态，不覆盖用户给定。

测试仍由`g_user_control`选择速度模式、经过原预充和启动互锁，使用正式PendSV PI。没有另写一个“更快但不等同正式程序”的速度控制器。

最后四个槽位沿用`current_test_sample_t`的成员名，但速度实验中含义如表，不能按电流实验字段解释。脚本、图和日志均按速度布局解析。

记录到达目标点数后，MCU清除用户和旧速度使能；即使电脑脚本退出也会按点数停止。另在输出关闭时配置既有5 s主机看门狗，作为独立上限。临时测试看门狗不作为正常连续运行的默认超时。

## 6. 时域和频域口径

### 6.1 阶跃

主要小阶跃为300→400 rpm。候选初筛先预运行0.3 s；最终增加预稳速时间，避免低Ki候选尚未到达初始平台就进行比较。

- 上升时间：反馈从本次阶跃幅值的10%到90%的时间。
- 超调：相对于阶跃幅值计算，不是相对于400 rpm计算。相同20 rpm波动，在100 rpm和200 rpm阶跃中对应的百分比不同。
- 末段均值/标准差：原始记录末100点，包含真实周期波动。
- IAE：阶跃之后相对斜坡后实际参考的绝对跟踪误差时间积分，单位rpm·s；它不把用户设定的斜坡本身算成闭环误差。`common_window_metrics.json`另存相对原始指令的`command_iae_400ms_rpm_s`，用于含斜坡的整个指令跟随评价。
- 合格调节时间：误差进入`max(阶跃幅值×2%,2 rpm)`且至少保持100 ms；没有满足就写未达到，不放宽误差带来让数据通过。

MATLAB最终使用`stepinfo`独立计算实测曲线。MATLAB插值和Python首次采样越界法可能有一条记录量级的差异；带保持时间的调节时间与`stepinfo`默认定义也不同，分别保存。

### 6.2 逐点正弦

在300 rpm偏置上注入±50 rpm正弦，测2、5、10、20、30、40、60、80 Hz。采用实际斜坡后参考与反馈的复幅值比；至少去掉激励开始后一个周期，再用`DC+sin+cos`拟合。保存残差，不将拟合后的正弦当成无噪声原始波形。

本次不是物理断开速度控制器的开环PRBS实验。使用正式闭环内的外部正弦激励，同时记录Iq参考，得到以下等效频响：

1. 速度参考→速度反馈：实测闭环频率响应。
2. 外部正弦参考→Iq参考：控制输出的相干基波。
3. 两者相除，并把rpm乘π/30：估计Iq参考→滤波速度(rad/s)的等效对象，包含电流闭环和测速链。

这样得到的对象仍受有限记录、周期扰动和非线性的影响，不能伪称独立开环验证。高频反馈幅值较小，残差可能大于基波；附带的分窗幅相离散程度用于检查记录内一致性，不是独立置信区间。

## 9. 当前源码调整

- `Modules/Encoder/Src/encoder.c`：测速低通τ从10 ms改为1 ms，保留1 ms差分窗口、原始角度合理性和新鲜度门。
- `Servo/Src/speed_commission.c`：先测0.04/0.5快速候选，完整扫频发现裕度不足后，默认改为MATLAB实测FRD候选0.030637519/0.13476460；增加测试期给定覆盖和录波观察，正常未请求测试时仍走原连续速度路径。
- `Servo/Src/user_control.c`：速度模式默认加、减速度从300改为9000 rpm/s，正反限速9000不变。
- `Core/Src/main.c`：加入测试请求的OFF边界服务。
- `Tests`：定长录波配置、共享缓冲与主机回归。

PI按rad/s误差计算：Kp单位A/(rad/s)，Ki按实际秒数积分。0.04并不是A/rpm。100 rpm约10.472 rad/s，对应约0.419 A比例电流增量；MATLAB辨识时已经把rpm换成rad/s，没有遗漏π/30比例。

加减速斜坡与闭环PI是两个概念：原默认300 rpm/s下，100 rpm指令变化本身就需要约333 ms；9000 rpm/s下约11.1 ms。这两个数是斜坡计算，不是伪造的实测闭环上升时间。辨识时采用100000 rpm/s以尽量排除斜坡限制，日常默认值另行验证。

上电自动启动开关、默认位置模式、位置目标、相电流策略及最高转速门均未改变。本次未重新验收位置外环和高速7000 rpm可靠性。

### 10.4 周期波动的进一步证据与不能下的结论

`diagnose_speed_ripple.py`、`ripple_diagnostics.json`及`speed_ripple_diagnostics.png`对原始数据进行描述性分析，不修改控制和校准表。

1000 rpm长记录在阶跃后0.151～1.996 s覆盖约30.69机械圈。按同一编码器机械角度拟合1～6阶谐波，2/4/5阶幅值约40.73/54.22/33.89 rpm，拟合解释约99.54%的反馈波动方差；残留标准差仍包含采样和非周期部分。1000 rpm的2/4/5阶约33.3/66.7/83.3 Hz，与快速候选高频峰值有频带重合。

这支持“波动具有明显机械角同步性，不宜仅当作随机ADC白噪声”的判断。**但角度和速度来自同一编码器，不能据此证明是编码器非线性，也不能排除真实的齿槽/换相/传动转矩波动。** 未获得独立高带宽转速基准前，没有写入未经验证的角度补偿或每转速度前馈。

长记录Iq参考RMS约0.437 A，采样Iq与其差的RMS约0.093 A。这是ADC及已有换算下的记录，不能当成独立电流探头测量，也不能仅凭它断言电流环绝对正确或错误。

`evaluate_iq_chain.py`还从外部速度正弦的相干基波估算Iq参考→Iq反馈有效链路。r2在60/80 Hz约为-0.67/-0.52 dB，-24.8/-32.9°。该链路包含发布、保持和记录时序，不是独立隔离的电流环带宽；2/5 Hz的电流基波较小，噪声残差约0.06 A，低频幅值比不宜过度解读。输出`effective_iq_chain.json/.png`与最终数据一同保留。

## 14. 必须保留的适用范围

这是一组固定电机、当前传动和用户卸载后的速度响应试验，不是满载、全温度或最高转速验收。没有独立高带宽测速计，不能只凭同一个编码器的原始角度与滤波速度证明绝对机械速度精度。

周期波动仍需单独区分机械/齿槽转矩、换相、电流纹波和编码器周期误差。仅凭频谱与转速有相关性不能确认哪一项是根因。本次不凭加大显示滤波来宣称控制波动已消失，也不把有限候选中的结果叫作全工况绝对最优。

速度PI和测速链也被位置模式的内层速度控制复用。本次没有修改位置目标或上电模式，但**位置全闭环的动态性能没有重新验收**，不能宣称位置性能完全不受本次参数变化影响。
