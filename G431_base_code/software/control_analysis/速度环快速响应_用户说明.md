更新关联（Codex，2026-10-29）：位置环当前为R17/Kp72，操作见[位置环用户说明](../docs/位置环调试与使用说明.md)、[带盘调试日志](../docs/log/2026-10-29_位置环续调与反馈链路检查.md)。本页速度环频响属于10-28实测条件，不表示已在新增惯量盘下重新验证约86 Hz；位置环本轮没有重新整定速度PI。

已完成：多组PI实机阶跃对照、正弦扫频、MATLAB整定和时域/频域分析。原始数据与详细日志全部保留。

当前编译参数：速度PI **Kp≈0.03064，Ki≈0.13476**；测速滤波1 ms；加减速度9000 rpm/s。电流PI未改。

300→400 rpm：正常加减速下实测上升约11.2 ms、超调约21%。仍有稳态波动，严格±2 rpm稳定要求未达到。1000 rpm速度反馈波动约55 rpm（标准差），不能称为全转速最优。

频域：-3 dB交点在80～100 Hz，插值约86 Hz；估算相位裕度58°，已测频点峰值约0.85 dB。

## Watch操作

1. `g_user_control.enable = 0`
2. `g_user_control.mode = 4`
3. `g_user_control.speed.target_rpm`填电机轴目标转速，建议先用300。
4. `g_user_control.enable = 1`启动；改回0停机。

后续改转速只改`g_user_control.speed.target_rpm`。不要只改旧的`g_speed_run.enable`。
