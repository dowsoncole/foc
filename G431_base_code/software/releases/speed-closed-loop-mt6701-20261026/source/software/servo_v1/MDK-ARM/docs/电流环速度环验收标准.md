> 适用工程：`G431_base_code/software/servo_v1`
> 依据：`Servo/Inc/speed_commission.h`、`Servo/Src/speed_commission.c`、`FOC/Src/foc_current_tuning.c`、
> `Modules/Encoder/Src/encoder.c`（速度估算）、`Tests/Inc/current_loop_test.h`
> 版本：2026-10-23
> 目的：为 Codex 提供可直接执行、可量化判定的电流环/速度环验收标准。
> ⚠ **范围说明**：位置环暂不做（用户 2026-10-23 明确收缩范围）。本文档只验收电流环与速度环，

## 0. TL;DR（给 Codex 的 30 秒版）

**本文档只验收电流环与速度环；位置环暂缓。** 但验收目标按"未来支撑位置环 20 Hz（最低 10 Hz）"的带宽裕量设定，避免将来返工：

| 环             | 目标值        | 最低验收值         | 关键风险                                    |
| -------------- | ------------- | ------------------ | ------------------------------------------- |
| 电流环闭环带宽 | ≥ 2 kHz      | **≥ 1 kHz** | 默认整定 200 Hz 太低，必须重设              |
| 速度环闭环带宽 | ≥ 150 Hz     | **≥ 60 Hz** | **速度滤波 tau=10 ms 是当前最大瓶颈** |
| ~~位置环~~    | ~~≥ 20 Hz~~ | ~~≥ 10 Hz~~      | 暂缓（依赖前两环达标，后续接入）            |

**第一个动作不是测试，是改造速度反馈路径**（滤波 tau 10 ms → ≤1 ms、差分窗口 20 点 → ≤4~8 点），否则速度环带宽物理上限被压在 ~16 Hz，后续一切免谈。

## 1. 带宽预算与推导依据（为什么是这些数）

串级伺服（位置 P → 速度 PI → 电流 PI）的经典带宽分级规则：

```
ω_position ≤ ω_speed / 5 ~ ω_speed / 10
ω_speed    ≤ ω_current / 5 ~ ω_current / 10
```

按此反推（取保守档 1/5，斜率 1 时相位裕度足够）。**位置环本身暂缓，但为它预留裕量**：

| 预留位置环目标      | 速度环需 ≥                   | 电流环需 ≥                |
| ------------------- | ----------------------------- | -------------------------- |
| 20 Hz（目标，暂缓） | 100 Hz（建议做到 150~200 Hz） | 0.5~1 kHz（建议 2 kHz）    |
| 10 Hz（最低，暂缓） | 50 Hz（建议 60 Hz）           | 250~500 Hz（建议 ≥1 kHz） |

工程上限计算（当前硬件）：

- 电流环采样 20 kHz：`ω_max = 2π × 0.1 × fs = 12.57e3 rad/s ≈ 2000 Hz`（FOC_CurrentDesign 的 0.1×fs 上限本身就卡在这）
- 整定延迟 `delay_s=75 µs`、相位裕度 60°：`ω_max = PM/delay = 1.047/75e-6 ≈ 13.96e3 rad/s ≈ 2222 Hz`
- **结论：电流环 2 kHz 是贴着硬件上限的目标线，验收线定 1 kHz 是稳妥的。**

## 3. 电流环验收标准

### 3.1 测试方法

- **激励**：`g_speed_test.kind = 2`（Iq 阶跃）或 `kind = 5`（Iq PRBS），使用 `current_loop_test` 框架；也可直接调 `FOC_CurrentDesign` 设目标带宽后上阶跃。
- **记录**：`speed_test_record_t`（`time_s / iq_reference / iq / id / voltage_q`），`record_divider` 按 1 ms。
- **工况**：转速 0（锁轴）与 500 rpm、1500 rpm 各一组；电流幅值 0.5 A / 2 A 两档；Vbus 记录实际值。
- **扫频确认**（可选但推荐）：`kind=5` Iq PRBS → 对 `iq_reference → iq` 做频响估计，直接读 -3 dB 点。

### 3.2 判据表（全部满足才通过）

| 指标            | 目标                    | 最低验收           | 测量方式                                                               |
| --------------- | ----------------------- | ------------------ | ---------------------------------------------------------------------- |
| 闭环 -3 dB 带宽 | ≥ 2 kHz                | **≥ 1 kHz** | PRBS 频响 / 阶跃 10-90% 上升时间 `tr ≤ 0.35/BW`（1 kHz→≤0.35 ms） |
| 阶跃超调        | ≤ 5 %                  | ≤ 10 %            | `(iq_peak - iq_settle)/iq_settle`，无持续振荡                        |
| 稳态误差        | ≤ 1 %                  | ≤ 2 %             | 阶跃末端 `(iq_ref - iq)/iq_ref`                                      |
| dq 耦合残留     | \|iq_due_to_id\| ≤ 5 % | ≤ 10 %            | id 阶跃时观测 iq 扰动                                                  |
| 纹波            | 峰峰值 ≤ 5 % 均值      | ≤ 10 %            | 稳态 1 ms 窗内 `iq` 峰峰值/均值（20 kHz × 4 过采样下）              |
| 饱和恢复        | ≤ 5 ms                 | ≤ 10 ms           | 限幅后撤指令，积分退出饱和并回到线性区的时间                           |
| 无振荡失稳      | 全工况                  | 全工况             | 任何组（含 2 A、1500 rpm）不得持续 ±10% 振荡                          |

### 3.3 参数指引（Codex 执行）

- 用 `FOC_CurrentDesign`：`bandwidth_hz ∈ [1000, 2000]`，`phase_margin_deg=60`，`delay_s=75e-6`，`sample_period_s=50e-6`。
- kp/ki 由公式给出（`kp=L·ω/Vdc`、`ki=R·ω/Vdc`），**R/L 必须用实测值**（该框架刻意无默认值）。
- 若 2 kHz 目标下出现振荡：先确认 Vdc 归一化（闭环链现缺母线归一化，见既有评估）→ 再降目标至 1.5 kHz。
- 积分限幅：从 `current_limit · L · ω` 量级估算，勿低于线性区所需。

## 4. 速度环验收标准

### 4.1 测试方法

- **前置**：完成 §2-P4 的速度反馈改造。
- **阶跃**：`kind=3`（step），幅值 500 rpm / 1500 rpm，记录 `reference / speed`。
- **扫频**：`kind=4`（sine，变频）或 `kind=6`（speed PRBS，`prbs_bit_ms` 设小）→ 频响估计读 -3 dB。
- **连续**：`kind=7` 连续模式，`g_speed_run` 遥测（`target_rpm / actual_rpm / iq_reference_a / iq_a / uq_pu`）。
- **工况**：空载 + 额定负载（如可加载）；正反两个方向各一组。

### 4.2 判据表（全部满足才通过）

| 指标            | 目标（为位置环预留裕量） | 最低验收（为位置环预留裕量） | 测量方式                                                                |
| --------------- | ------------------------ | ---------------------------- | ----------------------------------------------------------------------- |
| 闭环 -3 dB 带宽 | ≥ 150 Hz                | **≥ 60 Hz**           | kind=6 PRBS 频响 / kind=4 扫频峰值                                      |
| 阶跃超调        | ≤ 10 %                  | ≤ 15 %                      | `(speed_peak - speed_settle)/speed_settle`                            |
| 阶跃调节时间    | ≤ 20 ms                 | ≤ 50 ms                     | 进入 ±2 % 误差带                                                       |
| 稳态误差        | ≤ 1 % 额定              | ≤ 2 % 额定                  | 连续模式 `(target-actual)/target` @ 稳态                              |
| 纹波（速度）    | ≤ 0.5 % 额定 (rpm)      | ≤ 1 % 额定                  | 稳态 `actual_rpm` 峰峰值                                              |
| 电流限制可达    | `iq` 在限幅内单调建立  | 不触发 `fault`             | `g_speed_run.fault==0` 全程                                           |
| 无振荡失稳      | 全工况                   | 全工况                       | 任何组不得持续振荡；`uq_pu` 不得长期贴 `SPEED_RUN_VOLTAGE_LIMIT_PU` |

> 注意：速度环带宽 ≥150 Hz 时，速度反馈必须无显著延迟（tau ≤1 ms 前提下 OK）。
> `uq_pu` 长期贴 0.56（`SPEED_RUN_VOLTAGE_LIMIT_PU`）说明已达电压极限，带宽读数是假的，需降速或升 Vbus 重测。

## 5. 预留：位置环接入条件（暂缓执行）

**位置环验收暂不做**（用户 2026-10-23）。本文档目标是把电流环/速度环做到足以支撑位置环 10~20 Hz 的水平；
将来接入位置环时，需满足以下前提（这些正是本文档验收要保证的）：

1. 电流环闭环带宽 ≥ 1 kHz（§3 验收通过）；
2. 速度环闭环带宽 ≥ 60 Hz（§4 验收通过）；
3. 速度反馈延迟已随 P4 改造降到可接受（tau ≤ 1 ms）。

位置环本身的验收标准（‑3 dB ≥ 20 Hz / 最低 10 Hz、定位超调、稳态误差等）待位置环进入实施时另行制定，不在本文档范围。

```
阶段 0  审查与改造
  0.1  确认 P1~P3（编码器健康）——不干净先修，否则后面全是噪声
  0.2  改造速度反馈（P4）：tau 0.010→≤0.001，窗口 20→≤8；编译、跑空转确认无异常纹波

阶段 1  电流环验收（§3）
  1.1  锁轴 + 0.5 A 阶跃，过 §3.2 全部判据
  1.2  2 A / 1500 rpm 组，无失稳
  1.3  记录所有组的带宽/超调/纹波/饱和恢复，写入验收记录表

阶段 2  速度环验收（§4）
  2.1  阶跃 500/1500 rpm：超调、调节时间、稳态误差
  2.2  PRBS 频响：读 -3 dB 带宽，≥60 Hz（目标 150 Hz）
  2.3  连续模式长时间运行：fault==0、无振荡、uq_pu 不长期贴限

阶段 3  结论归档
  —— 验收表 + 原始记录 + 参数最终值，提交用户确认
```

**Codex 纪律要求：**

1. 每个判据给出**数值证据**（记录文件/表格），禁止"看起来稳定"这类定性结论。
2. 失败先查根因（改 tau 是否引入纹波？电流环是否饱和？Vbus 是否跌落？），**不要靠调大 kp 硬顶判据**。
3. 位置环暂缓：本任务只验收电流环/速度环。若后续要接位置环，先保证本文档 §5 的三项前提（电流 ≥1 kHz、速度 ≥60 Hz、tau ≤1 ms）——**不要在位置环增益上打补丁**。
4. 任何涉及安全（过流、过压、机械限位）的判断，以上电实测为准，代码审核不能替代。

## 8. 关键风险与已知限制（写给你们自己的提醒）

1. **速度滤波是当前最大瓶颈**：10 ms tau 意味着反馈 16 Hz 处 45° 滞后，不改造连 60 Hz 验收线都危险。
2. **电流环闭环链缺母线归一化**（既有评估结论）：Vdc 波动会漂移电流环增益，验收时固定供电、记录 Vbus。
3. **2 kHz 电流环贴着硬件上限**（0.1×fs 与 PM/delay 同时卡在 ~2 kHz）：若无法稳定，降目标到 1.5 kHz，但**验收线 1 kHz 不可妥协**（低于它速度环 150 Hz 悬）。
4. **编码器带载 CRC 问题若复现**：先按 `docs/encoder/spi_logic_analysis_2026-10-22.md` §8 处理（恢复链已重构，需实板确认），不要带着故障测环。
5. **速度纹波 vs 带宽的矛盾**：缩小窗口/tau 提升带宽会放大量化噪声，用 §4.2 纹波判据把关，必要时在速度环内做轻量滤波或前馈（补偿相位）。
