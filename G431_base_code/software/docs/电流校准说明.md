# 电流校准说明

本文说明当前程序从 ADC 原始值到物理安培的完整校准流程。详细实验数据见[U 相物理电流标定日志](log/2026-10-27_U相物理电流标定.md)。

## 1. 校准分为三部分

| 校准 | 解决的问题 | 何时执行 |
| --- | --- | --- |
| 上电零偏校准 | 零电流时 ADC 不正好位于中点 | 每次上电自动执行，约 1 ms |
| 静态绝对比例标定 | ADC 相差 1 count 到底代表多少 A | 更换板卡、运放、分流电阻或发现读数比例异常时执行 |
| 旋转一致性标定 | U/V 两条模拟链增益不一致时，旋转 Clarke/Park 电流是否仍与物理世界一致 | 静态标定后执行，或维修 U/V 模拟链后复核 |

上电零偏不能代替比例标定；静态比例正确也不能证明 U/V 两通道一致。编码器零点校准是另一项业务，与本文的电流校准无关。

比例标定完成后，需要按新的安培单位复核电流 PI。本工程已经把用户模式电流环默认值更新为 `Kp=0.05、Ki=100`；小信号阶跃上升约 1～2 ms，内部带宽约 500～600 Hz。实验曲线与适用范围见[电流环时域与频域优化](log/2026-10-27_电流环时域与频域优化.md)。

## 2. 当前物理定义和参数

程序规定：电流从逆变器流入电机相端为正。U、V 两相直接采样，W 相由 `-(U+V)` 重构。

| 项目 | 当前值 |
| --- | ---: |
| U/V 分流电阻 | 7 mΩ |
| U 相等效增益 | 16.89535 |
| V 相等效增益 | 17.53506 |
| U 相比例 | 0.00681389 A/count |
| V 相比例 | 0.00656530 A/count |
| ADC | 12 位，3.3 V，当前无过采样 |
| 电流环 | 20 kHz，周期 50 µs |

换算关系：

```text
Iu = polarity_u × (raw_u - offset_u) × 0.00681389 A
Iv = polarity_v × (raw_v - offset_v) × 0.00656530 A
Iw = -(Iu + Iv)
```

当前 `polarity_u=polarity_v=-1`。标定时 TCP0030A 箭头与程序正方向相反，所以 CH4 与程序异号；电流钳朝向只影响示波器符号，不能据此改变 FOC 极性。

## 3. 设备和接线

1. 将 TCP0030A 电流钳夹在电机 U 相单根导线上，记录箭头方向。
2. 电流钳接 MDO34 CH4，确认示波器识别探头型号，CH4 单位显示为 A。
3. 输出关闭时执行探头消磁/调零，并采集一段零电流波形。零电流均值应接近 0。
4. 保持 ST-LINK 连接，仅使用非停机内存读取；MOE 打开时禁止断点、单步或暂停 CPU。

本次设备为 MDO34 C064843、TCP0030A C022646。示波器 PyVISA 资源为：

```text
USB::0x0699::0x052C::C064843::INSTR
```

## 4. 每次上电自动零偏校准

程序初始化 OPAMP 和 ADC 后等待模拟链稳定，保持 `MOE=0`，随后采集 20 组 U/V 原始值，20 kHz 下约 1 ms。只有样本数量完整、范围合法且波动未超限时才提交新 `offset_u/offset_v`。

检查顺序：

1. 确认电机没有被驱动，`TIM1.BDTR.MOE=0`。
2. 检查 `g_current_sampling.calibration_state` 为 `CURRENT_SAMPLING_CAL_DONE`。
3. 检查 `offset_u/offset_v` 在 ADC 有效范围内。
4. 检查 `calibration_min/max`，确认 1 ms 窗口没有明显开关干扰或饱和。

零偏必须在无电流条件下采集。禁止在 MOE 打开时重新请求零偏校准，也不要用历史固定偏置覆盖本次上电结果。

## 5. 静态绝对比例标定

静态标定只校准被电流钳直接测量的 U 相。

### 5.1 参数设置

使用统一用户接口的无编码器开环电流模式：

```c
g_user_control.enable = 0;
// 等待 status.state == USER_IDLE
g_user_control.mode = USER_MODE_OPEN_CURRENT;
g_user_control.open_current.id_a = 0.5f;   // 逐点改变正负值
g_user_control.open_current.iq_a = 0.0f;
g_user_control.open_current.electrical_hz = 0.0f;
g_user_control.enable = 1;
```

电角频率为 0、初始电角度为 0 时，U 相主要承载 D 轴直流电流。建议从 ±0.25 A 开始，确认方向和保护状态后再测 ±0.5 A；需要扩大范围时必须受电机、功率级和电源能力约束。

### 5.2 采集和计算

1. 每个点等待至少 1 s，使电流环和探头波形稳定。
2. CH4 用自动触发采集不少于 0.4 s，计算平均值和标准差。
3. 正负对称点成对使用，斜率可消除桥臂非对称和小直流偏置：

```text
slope = (Iphysical_positive - Iphysical_negative)
        / (Icommand_positive - Icommand_negative)
```

4. 多个点用最小二乘拟合 `physical = slope × program + intercept`，检查 `R²`。
5. 修改 U 相 A/count 后重新下载，再做至少 ±0.5 A 复核。

静态标定不使用某一个瞬时 ADC 码与示波器瞬时点直接相除，因为 PWM 纹波和两个设备的采样时刻并不同步。

## 6. 旋转开环电流标定

旋转标定让 U/V 两条采样链在一个电周期内都参与 Clarke/Park 反馈。

### 6.1 推荐点位

| Id 峰值 | 电角频率 | 2 对极理论机械转速 | 用途 |
| ---: | ---: | ---: | --- |
| 0.30 A | 1 Hz | 30 rpm | 低电流分辨率检查 |
| 0.50 A | 2 Hz | 60 rpm | 主校准点 |
| 0.50 A | 5 Hz | 150 rpm | 主校准点和频率一致性检查 |

设置 `Iq=0`，逐点修改 `open_current.id_a` 和 `electrical_hz`。编码器不参与换相，但仍读取 `status.actual_rpm`，用于证明转子实际旋转并判断是否严重失步。

### 6.2 示波器分析

CH4 至少采集 4 个完整电周期，按已知电角频率拟合：

```text
Iu(t) = offset + A × sin(2πft + phase) + residual
```

记录：

- 基波峰值 `A`，它应接近 Id 指令；
- 基波 RMS，即 `A/sqrt(2)`；
- 直流偏置；
- 拟合残差 RMS，用于判断 PWM 纹波、谐波和低电流量化影响；
- MCU 的 Id/Iq 均值和实际 rpm。

采集脚本：

```powershell
python software/control_analysis/scripts/capture_rotating_phase_current.py `
  software/control_analysis/results/current_calibration/id0p5_5hz `
  --frequency-hz 5 --command-peak-a 0.5 --horizontal-scale-s 0.1

python software/control_analysis/scripts/sample_open_current_status.py `
  --samples 100 --interval-ms 10
```

前一个脚本只控制示波器并恢复其原设置，不会使能电机；后一个脚本只做非停机 SWD 读取，也不会修改控制参数。

### 6.3 如何区分比例误差和电流环误差

- 若 CH4 基波偏低，同时 MCU Id 均值也偏低：优先检查 PI 跟踪、母线电压或电压饱和，不应改 ADC 比例。
- 若 MCU Id 已接近指令，但 CH4 基波按相同比例偏差，并且 2 Hz、5 Hz 结果一致：说明主要是采样比例或 U/V 增益一致性问题。
- U 相静态比例正确、旋转时仍偏差：不能继续改一个公共增益。应保留 U 的直接标定，并根据旋转平衡电流推导 V 相比例，再重新实测。
- 低电流点受探头分辨率和 PWM 纹波影响更大。本次 0.30 A 点误差约 4.35%，没有用它覆盖 0.5 A 两个主校准点。

## 7. 当前最终验收结果

| 模式 | 指令 | CH4 结果 | MCU / 转速结果 |
| --- | ---: | ---: | ---: |
| 静态正向 | +0.50 A | +0.51028 A（按程序方向） | 故障 0 |
| 静态负向 | -0.50 A | -0.47219 A（按程序方向） | 故障 0 |
| 旋转 | 0.30 A，1 Hz | 基波 0.28694 A，-4.35% | Id 0.30431 A；29.31 rpm |
| 旋转 | 0.50 A，2 Hz | 基波 0.49254 A，-1.49% | Id 0.49924 A；59.07 rpm |
| 旋转 | 0.50 A，5 Hz | 基波 0.49323 A，-1.35% | Id 0.49786 A；150.01 rpm |

静态正负点的中心偏置约 19 mA，成对斜率约 0.9825；旋转 0.5 A 两点在约 1.5% 内且随频率一致。考虑示波器 10 mA 量化、PWM 纹波、模拟链温漂和静态正负不对称，当前参数不再按单个低电流点继续追调。

当前只完成 U 相电流钳的计量。V 相比例由 U 相静态结果和旋转平衡电流推导，尚未把电流钳移到 V 相独立复核。若要求逐相计量溯源，应分别把探头夹到 U、V 相重复静态和旋转测试。

## 8. 收尾和异常处理

每组测试结束必须：

1. 写 `g_user_control.enable=0`。
2. 等 `status.state=USER_IDLE`。
3. 读回 `TIM1.BDTR.MOE=0`。
4. 检查 `g_global_mode_control.runtime.fault_flags` 和 `g_foc_controller.fault_flags`。

若出现 `USER_BACKEND_FAULT`，不要直接覆盖故障变量。先保持 MOE 关闭，读取底层故障和驱动状态；本次曾遇到历史 `FOC_FAULT_POWER_STAGE` 锁存，重新上电并在 `main()` 初始化后显式关闭用户使能，确认驱动安全门和故障均为 0 后才继续。

以下变化后必须重新做完整流程：更换 PCB、分流电阻、OPAMP 外围电阻、ADC 参考、功率板、采样相序，或修改 ADC 过采样与数据右移方式。只修改 PWM/控制频率时至少重新验证零偏噪声和旋转 2/5 Hz 点。
