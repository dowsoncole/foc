# MEDIUM edge-rate comparison - did not fix the high-speed fault

Diagnostic candidate only. This is not the delivered operating configuration.

- Source snapshot is in `source/`; AXF/HEX/BIN match all 64112 load bytes.
- Same 10.5 MHz mode-3 SPI, 20 us phase and all current/feedback/thermal guards.
- CS/SCK/MOSI edge configuration alone changed from VERY_HIGH to MEDIUM.
- Target GPIOA OSPEEDR readback: 0xCC3F5503; SPI1 CR1 BR remains /16.
- Compared with the original baseline, all 92 changed load bytes are confined
  to HAL_SPI_MspInit and MX_SPI1_Encoder_Init. FOC/protection load bytes match.
- The RAM electrical offset was exactly the previous trial's float32 value:
  5.592228412628174 rad. Historical heat seed: 82.566 A^2*s, rounded upward.
- `../slew_highspeed_i2t_20261023/summary.json`: 8200 rpm held 10.485 s;
  next 8400-rpm stage stopped on CRC at frozen feedback 8378.100 rpm.
- First bad frame: FF FE AA AA AA AA, computed CRC 0A. CRC +1, angle-step
  rejects +28, no deadline overrun; sampled phase peak 5.567422 A.
- Same-field 3 A alignment estimates changed by -11.8198 electrical degrees
  across the high-speed test. Actual magnet displacement is not established.
- Candidate was reverted. `../glued_slew_reverted_20261023/firmware.bin`
  exactly matches the original baseline. Final output is OFF, RAM calibration
  inhibited, and next-trial heat-seed floor is at least 82.567 A^2*s.
- Reset removes RAM-only inhibition and reloads historical 5.3988-rad boot
  calibration, not the RAM offset used in these tests. Do not auto-resume.
