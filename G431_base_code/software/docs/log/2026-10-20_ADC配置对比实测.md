# ADC 采样保持与过采样配置对比实测

## 结论

本次实际编译、下载并测量六组配置，另重复验证最终配置。选用 profile 5，作为当前固定零电角度、低输出电流环投运的采样配置：

- ADC 异步时钟 42 MHz，12 位；
- 采样保持 12.5 周期（约 298 ns）；
- 注入组每通道 16 倍硬件过采样，右移 0 位；
- 原始值和零点均保留累加码，安培换算只除一次 16；
- 两通道完整转换约 19.048 µs，PWM 仍为 20 kHz；
- 保持 0.25 A 相电流保护，没有额外软件低通，也未开启功率输出。

这是在所测候选中噪声最小的投运选择，不是对所有转速、带宽和调制度的通用最优配置。噪声仍存在，未宣称硬件电路存在故障，也不能仅凭这些测试证明全部噪声都来自 ADC 内部。

## 对比方法

新增 `g_adc_noise`，仅在 output_request=0、output_armed=0、MOE=0 且校准完成时启动，在 ADC 回调中连续保存 1024 对原始码。

每组重启并重新做原有 400 点零点校准，再通过调试器启动采集。采集期间 CPU 自由运行；采集完成后才读取冻结缓存。所有组 sample_sequence 尾首差均为 1023，约覆盖 51.2 ms。比上轮 80 次 SWD 非同步读取更适合比较噪声。

统计量为去均值标准差，不是含偏置 RMS。W=-U-V，不是第三路独立 ADC。各组并非同时采样，短记录的峰值有随机变化，不是长期最坏值保证。

## 时序代价与适用范围

两通道不是同时转换，16 倍下 U/V 有约 9.524 µs 的采样中心时间差。未来提高转速/带宽时，应重新评估该误差，必要时使用双 ADC 同步采样，而不是一味提高过采样倍率。

换算公式：

```text
每通道时间 = (采样保持周期 + 12.5) × 过采样倍率 / 42 MHz
完整序列时间 = 每通道时间 × 2
相电流 = polarity × (raw - offset) × 3.3 / (4095 × 0.007 × 6.1 × 倍率)
```

16×4095=65520，未右移累加值仍能装入现有 uint16_t。400 点零点累加也在 uint32_t 范围内。电流原始码分辨率因保留累加位而提高，但这不代表绝对精度等比例提高。

代码由同一 profile 同时生成 HAL 采样参数、换算倍率和 PWM 序列时间，避免只修改 ADC、不更新触发窗口。

最终实机回读：

- planned_trigger=2269，planned_sequence_end=5470；
- low_window_start=2269，low_window_end=6129；
- window_rejections=0，deadline_rejections=0；
- duty_min=0.0202381，duty_max=0.5783333；
- 实际采样周期约 49.988 µs，runtime fault_flags=0；
- BDTR=0x02002054，MOE=0；
- ADC CFGR2=0x0000000E（注入过采样、16 倍、右移 0）；
- SMPR1=0x00000400，SMPR2=0x00000080（通道 3/12 均 12.5 周期）。

较长转换明显缩小了允许占空比范围，不能用于高调制度而不重新评估。当前仅验证中性 PWM 计划和关闭输出下的采样；尚未验证有开关电流时的噪声、计算截止时间和 D/Q 响应。

## 文档依据与未完成项

采样保持时间需结合信号源和 ADC 采样电容充电要求选择，不能只依据“运放输出所以最短档必然足够”。参考 [ST AN5346](https://www.st.com/resource/en/application_note/an5346-stm32g4-adc-use-tips-and-recommendations-stmicroelectronics.pdf)。
