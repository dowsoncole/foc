# 最高转速续测记录 — 2026-10-23

本轮短时完成 8200 rpm 档保持：反馈均值 8199.359 rpm，范围 8197.519–8201.655 rpm，
持续约 5.83 s。当档 CRC、角度跳变与超期均为 0；升 8400 档后失败，8500 rpm 尚未通过。

关键发现：两点对齐平均电角度零点原为 0.75076489 rad，运行后再次同角度对齐得到
5.13027293 rad，最短变化约 **109.075° 电角度**。用户确认磁铁/连接件可能打滑。
需要先断电检查、固定磁铁/联轴器及编码器板，再重新标定。软件暂不能确定具体哪个
部件发生位移，SPI 错误也仍需在连接可靠后复验。

当前输出已关闭，并将 RAM `calibration_ok=0`；I²t 一次性授权已消耗，热债
82.562935 A²·s 保留。这个禁止不是跨断电持久化设置；重新上电后必须重新校准，
不要沿用固件默认零点 0.7508 rad 直接启动高速。
