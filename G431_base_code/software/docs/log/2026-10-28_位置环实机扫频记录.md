## 当前结论

- 实际连接并烧录了伺服板，使用 J-Link `150710982`。输出轴反馈维持 MPT；速度环 PI 保持 `Kp=0.030637519, Ki=0.13476460`；电流策略保持硬件 OCP / `FLT_MAX`。
- MPT 请求、成功帧和运行中的位置更新率约 1 kHz。非原子调试快照的读出时间存在偏移，个别差分结果略大于 1000 Hz，不能解释为超过 1 kHz 的实时保证。
- `Kp=20 /s`、限速 2500 rpm、关闭测试轨迹速度前馈时，±2° 扫频 −3 dB 交点约 **4.01 Hz**。这是本轮对照工况，不是原默认 `Kp=2` 的实测带宽。
- `Kp=80 /s`、2500 rpm 时，±2° 基波幅频的 −3 dB 交点约 **9.03 Hz**，但已限幅，**不是有效线性闭环带宽**。
- `Kp=80 /s`、4500 rpm 时，±2° 在 7 Hz 的基波增益约 **+0.21 dB**、相位 **−37.21°**，速度指令未到限幅；9 Hz 开始出现速度指令限幅。10/12 Hz 的基波增益约 −0.98/−3.93 dB，插值交点约 **11.33 Hz**，同样**不能作为线性带宽验收**。该工况 20 Hz 仅 **−12.75 dB**。
- 上述完整 4500 rpm 扫频中，采样相电流峰值（从本次位置模式 arm 开始累计）约 **5.27 A**。这是相电流峰值，不是 RMS，也不是各频点独立峰值。
- 不能声称已达到 20 Hz，不能声称已找到最终最优增益。前馈比选、更高增益比选、完整小信号扫频和硬件阶跃测量尚未完成。

## 本轮修复

1. P0：旧脚本不再硬读 trace 的 1616 字节/100 行；从匹配 ELF 解析 `sizeof`，再按实际 `trace_count` 有界读取。修复 position 少读 4 字节，旧分析器不再假定固定 100 行/0.4 s。
2. 新入口 `measure_position_response.py`：Flash 完整匹配后才允许 RAM 写入；支持逐频扫频、前馈增益、位置增益、测试限速和有限阶跃。默认只读；运动需 `--run`。MCU 的独立失联停机超时配置为 10 秒。所有正常/异常退出尝试关闭输出，不自动清除底层故障。
3. 原参考幅值门槛错误地把参考幅度当作误差上界，阻止大增益下的 ±2° 测试。改为允许大信号试验，实际限幅时拒绝线性 FRD。
4. 原起振包络在一个周期内先从 0 升到 1，再回到 0，随后跳到 1。改成单调半余弦起振，并加入一个周期的平滑收尾，排除首尾过渡的解调样本。轨迹缓冲保留稳态尾窗，不再只记录起振片段。
5. 增加测试前馈系数（0～1），可独立测反馈闭环。有限阶跃使用 `frequency_hz=-1`，50 ms 预触发，MCU 有限时长执行；实机阶跃尚未执行。
6. 修正“正相位必定非因果”的错误判据：因果系统可以有相位超前，主值相位也会在 −180° 处折返。保留独立解析相位测试，取消按正负号直接拒绝数据的 `reject=6`。旧注释仅为历史记录，以头文件顶部修正说明为准。
7. 高增益时 1 个 MPT 量化单位即可产生大于 5 rpm 的 P 输出。原固定起振门槛会误拒绝已定位的下一频点。扫频/阶跃起振容差增加与增益和 2 个编码器量化单位对应的速度容差，位置误差、绝对角度、故障和运行互锁继续生效。
8. 位置模式测试上限允许到 4500 rpm，低于既有速度模式 7500 rpm 的实测工况；普通上电默认仍为 2500 rpm，未将试验增益固化为上电默认。位置加速度斜坡保持 200000 rpm/s。
9. 链接时发现新增能力使 SRAM 超出 40 字节。轨迹容量从 81 缩至 64，恢复 272 字节，所有新读取从 ELF 获得长度。堆/栈未缩小。旧 40 s 轨迹的记录点数因此减少，旧读取器不能继续假定 81/100 行。

## 断连后新增的离线补丁（R4，尚未烧录）

- 原 `valid` 只检查速度指令幅值，没有检查速度斜坡限制。增加 `slew_limited_samples`：稳态请求速度的变化率超过既有速度斜坡时，按 `reject=2` 拒绝线性 FRD。R3 的“速度未限幅”不能据此自动升级成“完全线性”。
- MPT 追加 DWT 微秒级 `resp_latency_last_us/max_us`。此前 0 ms 只说明延迟被 1 ms 分辨率隐藏。一组上电/arm 过程曾记录 15 ms 最大值，后续运行没有增长；不能把该累计最大值当作每帧运行延迟。新字段需实测复核。
- ABI：`output_position_t=56`、`output_position_test_t=68`、`mpt_t485_t=108`、FRD=40、trace 数组=1024 字节。
- Keil 构建日志：`tmp/position_build_r4.log`，0 errors / 0 warnings；`Code=85860, RO=1432, RW=5428, ZI=27140`。SRAM 余量仍有限，不应扩大记录数组。
- 位置主机回归（`-Wall -Wextra -Werror`）、用户入口/真实 dispatcher 回归及四个离线分析测试通过。斜坡门槛已有专门拒绝用例；解析滞后/超前、含 DC 的独立幅相拟合、计数器回绕和重复时标拒绝已覆盖。
