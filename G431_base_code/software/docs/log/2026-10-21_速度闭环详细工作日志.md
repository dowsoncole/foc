# 2026-10-21 速度闭环详细工作日志

## 1. 目标、边界及用户确认

目标：从原固定电角度 D/Q 电流闭环升级为随转子角度换相的电流内环，并接入速度 PI 外环；实测选择候选增益，提供时域和频域证据。不能把单次最佳值称为全工况最优，也不能把仿真冒充实测。

用户已确认：允许电机实际转动；2 对极；编码器测电机转子轴而非减速器输出轴；额定相电流 5 A；型号为所附 AM-BL4060BF 参数表的 2409 列。减速器虽不作为测量轴，若实际仍连接，其摩擦和反射惯量仍会影响本次结果，不能从模型中自动消失。

厂家图片（用户提供，并非本次独立测量）的参数：24 V；空载 9095 rpm；空载电流 375 mA；最大连续转矩 177.03 mN·m；推荐额定转速 8534 rpm；最大连续电流 7400 mA；端电阻 0.22 Ω；1 kHz 电感 0.04 mH；机械时间常数 2.72 ms；转动惯量 86.51 g·cm²=8.651×10⁻⁶ kg·m²；转矩常数 25.2 mN·m/A；转速常数 379 rpm/V。

注意：用户的额定相电流 5 A 与图片最大连续电流 7.4 A 不是已确认相同定义，本次不按 7.4 A 放宽保护。端电阻、端电感未确认为相值或 dq 值。Kt 的电流定义也未核实。因此未据这些数值直接覆盖已经验证的电流 PI，也未声称电机 R/L 已被辨识。

## 3. 新控制链与文件

`Servo/Inc/speed_commission.h` 和 `Servo/Src/speed_commission.c` 是有界投运模块，接入 `main.c` 的电流 PI 测试路径。工程枚举仍叫 CURRENT_OPEN_LOOP，但当 `g_speed_test.state!=0` 时，电角度与给定由新模块产生；不能仅看旧枚举名字判断速度闭环是否运行。该模块不是已验收的无限时长生产运行模式。

链路：编码器原始角度 → 方向/跨圈处理 → 电角度与机械速度 → 速度 PI → Iq 指令 → D/Q 电流 PI → PWM。速度模式 Id 指令为 0；只有方向/零位对齐时使用固定/缓慢旋转的定子电流矢量。

新增状态：0 idle、1 armed/反馈预备、2 running、3 done、4 fault。命令 1 武装、2 中止、3 返回 idle。武装并不自动输出；独立安全检查后才请求启动。每次 0.05～12 秒，MCU 用 DWT 自行超时关断，与电脑脚本是否退出无关。DWT 32 位在 168 MHz 下约 25.6 秒回绕，单次测试短于此限制，差值使用无符号计算。

模式：1 对齐扫角、2 转子坐标系 Iq 脉冲、3 速度阶跃、4 带直流偏置的正弦速度给定。速度 PI 目标约 1 kHz，用实际更新间隔积分；电流 PI 在运动测试中也使用相邻调用 DWT 实际间隔，避免漏周期时仍按 50 μs 积分。

Kp 单位 A/(rad/s)，Ki 单位 A/rad；输出为 Iq（A），不是电压 pu。与电流内环的 Kp=0.0025 pu/A、Ki=1.6 pu/(A·s) 不可混用。

抗饱和：积分先限幅；若积分使输出进一步超限则拒绝该积分增量；最终 Iq 再限幅。速度阶跃没有人为加慢给定斜坡，分析中可看到启动超调。

## 4. 安全限制及预备检查

- 初期电流上限 0.1 A；用户提供 5 A 额定值后，运动测试允许到 0.5 A，实际相电流保护提高为 0.8 A，仅在运动测试 armed/running 有效。
- 原固定角度电流测试仍保留 0.25 A 相电流关断阈值。
- 电流矢量限幅 0.5 A；归一化电压上限 0.02 pu；电流 PI 积分上限 ±0.01 pu，未提高母线电压能力。
- 本轮速度上限 10 rad/s（约 95.5 rpm）；配置硬上限 20 rad/s，给定幅值加偏置不得超过配置速度上限的一半。
- 无有效方向/零位配置禁止进入转矩/速度模式。停止后才可应用编码器配置。
- 传感器报警、非有限速度、角度超龄、调用间隔超过 0.5 ms、超速均拒绝继续输出。
- 上电默认输出关闭。对齐与速度测试结束后关闭输出，而不是维持最后给定。

## 5. 问题发现和修复过程

### 5.1 速度滤波的时间口径错误

原测速使用 20 个编码器样本作差分窗口，但每次新样本更新滤波器时也使用整个差分窗口的 dt 计算 alpha，导致标称 10 ms 滤波时间常数不成立。现区分差分窗口 dt 与相邻滤波更新 dt，后者用于 alpha=dt/(0.010+dt)。这会影响频域相位，不能把旧速度信号与修正后当作同一测量链。

### 5.2 DMA 调度、CRC 和有时限的坏帧处理

首测 `align_first` 只有一个记录点，state=4/fault=4，运行已关断；低优先级 DMA 完成处理可能被电流 ISR 推迟。将 DMA RX/TX 中断优先级从 2 改为 0，低于/高于的关系按 Cortex-M 数字越小越高理解：现在它们可抢占 ADC 优先级 1。之后必须重新测完整 ADC ISR 时间，不能只测电流算法函数。

随后发现 CRC 错误。SPI 从 10.5 MHz 降至 5.25 MHz 后情况变差：`align_spi32`、`neutral_spi32` 在零/极小给定附近就停机，读取时累计约 234/240 次 CRC 错误；这些累计数包含调试停顿和测试前后采集，不能当成精确的通电错误率。最终恢复 10.5 MHz。

启动时要求连续 100 次有效读取，再开始非零测试；200 ms 仍不能满足则故障退出。对单个 CRC 坏帧不发布错误角度，而保留上一帧正确数据及其原时间戳，仅在原有 150 μs 有效期内使用。连续错误使旧数据过期后仍停机；没有刷新旧时间戳、没有取消 CRC 校验。CRC 计数始终保留，通信干扰的物理原因尚未确认。

### 5.3 对齐电流不足与方向识别

0.1 A 对齐，电角度扫 +π/2，编码器总变化仅约 -0.054 rad，不足以可靠标定。用户确认直接测转子轴及额定 5 A 后，改为 0.5 A。正扫与反扫都产生明显相反方向运动，确认编码器方向应为 -1。

对齐记录包含最初拉入零位的运动，不能把“全程总机械位移”直接除以电角扫幅估算极对数。极对数 2 来自用户确认，而非这些短测重新辨识。

`align_zero500` 用 0.5 A、定子电角 0 保持 3 秒；取通电末段 20 点机械角平均约 5.22848337 rad，计算 offset=wrap(2×5.22848337)=4.17378143 rad。方向 -1 后使用 theta_e=wrap(2×theta_mech_directed+offset)。不使用停机回弹后的角度。此为低电流初步零位，存在摩擦/负载偏差，未当作高精度出厂标定。

`torque_positive` 在转子坐标系给 +0.1 A Iq，机械角按所选正方向增加约 0.889 rad，验证转矩符号。此校准仅保存在 RAM，重启后不自动作为已确认零位使用。

### 5.4 电流中断预算再检查

固定角度阶段的时间裕量不能直接沿用到旋转角度+编码器+速度计算。早期运动测试完整 ISR 最大约 9000 cycles，超过 8400 cycles/50 μs，超时多次。

优化措施：Park/逆 Park 复用 sin/cos；将区间归约后的正弦采用 11 次单精度多项式；参考矢量模长使用缩放公式避免通用 hypotf；ADC 每周期只换算一次相电流，同时供保护与反馈使用；速度限幅用简单比较；运动有界测试期间不重复构造 UART 快照，改用 RAM 时间戳记录。原电流测试串口路径保留。速度正弦给定只在约 1 kHz 外环计算。

多项式在 [-π/2,π/2] 的 float32 数值检查（200001 点）最大绝对误差约 1.79×10⁻⁷；这是数值抽查，不等于完整目标 C 回归测试。完整 FOC 主机测试本轮未取得可用 MSVC/Zig 工具链，不能声称通过。

最终 `tune_p10_i05`、`tune_p15_i05`、`tune_p15_i10` 诊断中累计 ISR 超时均为 0，最大约 8107 cycles（48.26 μs）。但最大调用间隔仍约 14492 cycles（86.3 μs）：**ISR 不超时不等于每次采样都严格间隔 50 μs**。本轮积分使用实际 dt，时域/频域记录使用 DWT 实际时间，不宣称已完成严格周期抖动验收。剩余实时裕量较小。

## 6. 数据与指标定义

每次 MCU 记录最多 128 点；字段为 `<8f`：时间(s)、给定、机械速度(rad/s)、Id(A)、Iq(A)、Iq给定(A)、机械角(rad)、Uq(pu)。Id/Iq 是上一控制输出的反馈快照，相比速度读取约差一个内环周期。没有把这些稀疏瞬时电流当作全速纹波谱。

2 秒阶跃使用 16 ms 记录间隔，约 125 点。前 0.2 秒给定为 0，之后阶跃。末段指标取最后四分之一记录，约 0.5 秒。均值/标准差基于编码器滤波后的速度，非独立测速仪。

- 稳态误差：给定减末段平均速度。若仍有明显波动，称“末段”而非已经收敛。
- IAE：按实际时间梯形积分 |给定−反馈|，单位 rad。
- 超调：所保存离散点的最大值相对给定；可能漏掉记录点之间峰值。
- t10/t90：首次达到给定 10%/90% 的采样时刻，减去 0.2 秒；时间分辨率受 16 ms 记录限制，噪声/反复穿越会影响结果。
- 调节时间：之后所有记录都进入 max(2%×给定幅值,0.05 rad/s) 的误差带。null 表示在本次记录内没有保持在带内，不能报告成 0 或忽略。

频域测试用有偏置正弦给定。舍弃前 max(0.2 秒,记录长度25%)，分别拟合参考和速度的 sin/cos/DC 分量，复比值得到闭环传递 T=速度反馈/速度给定。输出幅值 dB、相位 deg、拟合残差 RMS、有效周期数。它包含速度估计滤波、内环、负载及非线性，**不是开环传递函数**；不能凭此直接报告增益裕度/相位裕度。周期数不足或残差较大时，只作为局部经验响应。

## 10. 用户要求切换为 PRBS + MATLAB（追加，不抹去前序过程）

用户明确要求停止逐组实机试调，先测无控制器系统的 PRBS 响应，再用 MATLAB 工具自动整定并评估时域/频域。执行口径：**旁路速度 PI，保留 D/Q 电流内环与全部安全保护**。辨识输入为 Iq 指令(A)，输出为编码器机械速度(rad/s)，得到的是“电流闭环+机械系统+测速滤波”的速度环被控对象，不是直接电压到裸电机的模型。

已实际启动本机 MATLAB R2025b Update 1；Control System Toolbox、System Identification Toolbox 可用，idinput/tfest/pidtune 路径已确认。环境输出保存在 matlab_environment_check.log。不是将 Python 拟合结果冒充 MATLAB 结果。

新增 kind=5：速度 PI 不参与计算；前 .2 秒 Iq=0，随后每 16 ms 按 MATLAB 生成的 127 位 PRBS 切换 Iq。每 8 ms 保存实际 DWT 时间、实际送入电流环的 Iq 指令、速度。最多 336 个三浮点记录，复用原 128×8 浮点记录的 union 内存，避免增加大缓冲区导致 32 KB SRAM 溢出。单次最长 2.6 秒，本轮正式记录 2.4 秒；限流 .2 A、PRBS 幅度 ±.1 A、速度保护 10 rad/s。

MATLAB 脚本 matlab_prepare_prbs.m 使用 idinput(127,'prbs',[0 1],[-1 1])，固件按 16 ms 位宽执行。验证序列循环移位 37 位，另外进行一次物理采集；它不是独立频谱的新随机信号。原始序列及回读都保存，估计/验证不使用同一条实测记录。

### 13.2 旁路的控制器范围

kind=5 始终是速度 PI 旁路，输入为 Iq 指令，输出为编码器滤波速度；D/Q 电流闭环、编码器电角度、限流、限压、超速、反馈失效保护继续生效。所辨识对象因此包含电流内环、电机/负载、编码器测速滤波，并非裸电机的电压到速度传递函数。不能将该模型与电流内环再次串联，否则会重复计算内环动态。

## 14. 对上一轮失败的定量审计

离线脚本：`scripts/matlab_audit_speed.m`。输入为上一轮保存的原始数据及 MAT 模型；输出 `results/matlab_method_audit/`，不启动电机。

### 14.1 已排查的几种解释

1. **初始条件不是主要解释。** 原 OE2 模型独立验证分数：估计初态 52.5478%，零初态 52.3782%，差约 .17 个百分点。不能把 31% 实测超调与 0% 预测超调的差别解释成 compare 初态选项造成。
2. **已保存的阶跃点没有触及速度 PI 的 .3 A 指令限幅。** 三次试验 Iq 指令峰值约 .1991/.1901/.1508 A，保存点限幅比例为 0。记录间隔 16 ms，无法据此严格排除点间短暂事件；但现有证据不支持“主要是 .3 A 限幅导致超调”。
3. **电流反馈与给定存在可见差异。** 三次阶跃在 t>.3 s 的 Iq 误差 RMS 约 .0315/.0337/.0329 A。这里包含真实电流动态、采样误差及噪声，不能直接称为纯 ADC 噪声。
4. **原模型动态不足有工具证据。** MATLAB advice 对模型与验证数据明确提示动态未被充分描述，并提示残差非白。对原始数据的反馈/非线性统计提示也被保留，但不据统计提示反向断言固件中偷偷启用了速度 PI；固件 kind=5 的实际路径已经核对为旁路。

### 14.2 离散转换核查

原 OE2 的离散模型 Ts=.008 s，系数约为分子 `[0,6.2649,-4.8609]`、分母 `[1,-1.6851,.7651]`（z^-1 表示）。

| 转换 | 连续直接项 D | 旧 PI 加 1 ms BackwardEuler/ZOH 实现后的预测相位裕度 | 预测超调 |
|---|---:|---:|---:|
| Tustin | -3.224697 | 63.60° | 0% |
| ZOH | 0 | 74.96° | 0% |

在 8 Hz，两种转换幅值差约 .167 dB、相位差约 -10.657°。Tustin 转换产生 s=+250 的零点和非零直接项，不适合直接解释为电机的物理瞬时速度响应；它仍是数学上的频域近似，不应简单称为 MATLAB 算错。

更重要的是：两种转换仍都预测 0% 超调，而实测明显超调，所以**仅更换 d2c 方法不能解决本次模型与实际不一致**。同样，修正数字积分公式是实现一致性工作，不是已证实的全部根因。具体数值见 audit.json，图见 old_open_prbs_audit.png。

## 15. 发现并修正 PRBS 更新与记录不同步

### 15.1 复测如何发现问题

先不改固件，以零偏置 ±.10 A、16 ms/位、8 ms/点重新采集两组 10.4 秒 PRBS，标签 `speed_prbs_retry_est/val`，各 1300 点、均正常 DONE、无保护故障。舍弃首个完整周期后，比较后续 4 周期同一相位的输入：一致比例仅 **98.2940% / 97.1129%**。

### 15.2 固件修改及边界

文件 `Servo/Src/speed_commission.c`：

- 以 DWT elapsed cycles 推导统一的整数 elapsed_ms。
- kind=5 的 PRBS 边沿与记录器共用该时间基准，在同一 ADC 控制周期内确定指令和记录。

### 17.1 数据处理与模型候选
