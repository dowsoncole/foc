# TIM1 控制周期调整为 50 µs

## 变更目标

将 TIM1 主载波以及由它同步触发的编码器采集、ADC 采样和 FOC 电流环从 100 µs 调整为 50 µs。速度环仍为约 1 kHz，位置环仍为 200 Hz；编码器 SPI 保持 `/32`，实际 SCK 约 5.25 MHz。

## 当前配置

- TIM1 时钟：168 MHz，中央对齐计数，`RCR=1`。
- `ARR=4200`，完整载波周期为 8400 个计数，即 50 µs / 20 kHz。
- TIM1 更新中断在每个载波谷值发起一次编码器 SPI DMA。
- ADC 采样完成后执行 FOC，并在当前载波允许的截止时间前提交下一组三相比较值。
- ADC 序列优先在载波峰值前 5 µs 完成，为约 22.5～23 µs 的控制路径和 2 µs 提交保护留出余量。

## 首次实机失败与修正

仅把 `ARR` 从 8400 改为 4200、仍让 ADC 序列靠近载波峰值完成时，实机立即触发一次 `PWM_COMMIT_FAULT_BEFORE_GUARD`：写入前只剩 183 个定时器计数（约 1.09 µs），小于 337 个计数（约 2.01 µs）的提交保护。

修正后，采样规划器增加 `preferred_lead_ticks`，默认目标为序列在峰值前 5 µs 完成；若三相开关边沿使目标点不安全，仍在有效低侧采样窗口内选择距离目标最近的可行点。该修改只改变采样时刻，不改变占空比、ADC 过采样倍率和 FOC 功能。

## 验证结果

- 主机测试全部通过，包括 7200 个电角度采样窗口检查。
- Keil 目标构建 0 error、0 warning。
- 实机停机计时夹具读取：`TIM1->ARR=4200`，`MOE=0`。
- 采样窗口拒绝和截止拒绝均为 0，PWM 提交故障为 0。
- 成功提交的最小剩余时间为 982 个计数，约 5.85 µs。
- DWT 记录 128 个周期：ADC/FOC 完整路径平均约 24.81 µs，最大约 26.76 µs。
- 示波器 PA0 普通周期约 22.48～22.52 µs，带 1 kHz 外环请求的周期约 23.08～23.10 µs；相邻控制周期约 49.82～49.97 µs。

验证证据保存在 `software/control_analysis/results/tim1_50us_20261027/`。本轮为了安全仅在 `MOE=0` 下验证调度、时序和提交余量，没有替代带电机负载的闭环动态验收。
