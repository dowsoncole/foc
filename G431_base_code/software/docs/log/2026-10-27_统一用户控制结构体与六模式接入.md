# 统一用户控制结构体与六模式接入

日期：2026-10-27。工程：`software/servo_v1/MDK-ARM/servo_v1.uvprojx` / `servo_v1`。本次为源码、主机测试和 Keil 编译验证，未烧录新固件、未进行六模式带电实测。

## 需求及接口

新增 `volatile user_control_t g_user_control`，位于 `Servo/Inc/user_control.h` 和 `Servo/Src/user_control.c`。包含 enable、mode、电压/校准/无编码器电流/转矩/速度/位置参数组，以及只读状态组。

模式值 0～5 依次为电压、校准、开环电流、转矩、速度、位置。电压 V、电流 A、电角频率 Hz、电机速度 rpm、加减速 rpm/s、输出轴位置 deg。默认 enable=1、位置模式、目标 0，保留之前的自动启动和位置保持默认值。

默认电流零偏每次上电采集 20 帧/约 1 ms，TIM1 周期 50 µs、20 kHz，SPI1 /32、约 5.25 MHz 均沿用本次修改前配置。

## 执行接入

`user_control_dispatch.inc` 是 main.c 装配的应用适配段，使用 main 中已有的控制器和硬件入口。单独保存这一段，使主机测试能够编译与固件完全相同的命令调度代码。它不是独立编译单元。

- 主循环发布状态，校验用户参数，将六种模式转换为原有运行接口。停机先撤去 request/armed，停止 FOC 并关闭 MOE。模式切换至少经过一个关闭输出的主循环边界。
- 电压、开环电流、转矩在 `CURRENT_OPEN_LOOP` 历史分支中执行，使用 DQ PI 阶段。电压模式选择 ControllerVoltageStep，读取用户 D/Q 伏特值；开环电流和转矩选择 ControllerStep。
- `MainFoc_ReadFeedback` 对前三种直接给定模式调用 UserControl_FastReference。电压/开环电流角度由频率积分，完全不读取编码器角度；转矩模式只使用有效电机编码器电角度。
- 电流仍来自正式 ADC 反馈；电流校准、READY/nFAULT、输出预充电和 PWM 提交门仍使用现有链路。
- 速度复用连续执行 kind=7，1 kHz 外环维持 PendSV 调度。新增用户加/减速率与正/反速度限值，反转时按减速度先到 0，再用剩余时间按加速度反向增加。
- 位置复用 OutputPosition，主循环 200 Hz。取消 0～360°目标和实际位置限制；累计计数改 int64_t，保留通信新鲜度、单帧跳变、方向、参数与执行故障检查。

## 位置坐标

每次位置模式重新使能时捕获 position_origin，用户目标是相对此原点的累计坐标，内部目标=origin+用户目标。运行中改变目标不重置原点。位置目标 720 表示从使能位置正转两圈，-180 表示反转半圈；从720修改到180是返回该半圈坐标。

底层记录仍保留自身坐标，用户状态 actual_position_deg 扣除本次原点。多圈数值没有原先的 360°软件边界，但 float 显示与目标在极大累计位置下会损失角度分辨率，不承诺无限精度或断电记圈。

## D/Q 编码器校准

原有 encoder_calibration_config_t 尾部增加 q_voltage_v，保留前两个字段的顺序。默认 Ud=1.5、Uq=0、3 s。实际执行器使用锁定的 D/Q 电压，幅值校验使用 hypot(Ud,Uq)，仍受 2.8 V 和名义母线10%双重约束。

零点公式变为：

```text
offset = wrap(atan2(Uq,Ud) - direction * pole_pairs * raw_angle * 2π/2²¹)
```

即将非零 Uq 形成的磁场偏角纳入校准。采样在 ADC 执行器结束前捕获；保存和应用仍只发生在输出关闭后。Flash 格式、地址、版本、CRC、双页轮替和 commit 保持原样；电压元数据写合成幅值，因此 Q-only、负 D 等合法矢量仍能保存。上电读取旧零点记录不受结构体扩展影响。

校准完成后 USER_DONE，不重复启动；取消时不保存中间角度，若有旧有效零点则保留，释放原执行器与参数备份。其他底层故障不自动清除。

## 状态与使能

state：IDLE/STARTING/RUNNING/DONE/FAULT。fault：OK/BAD_PARAMETER/NOT_READY/BACKEND_FAULT。enable=0立即撤去输出，不解释为速度斜坡停车；参数写入应先关闭使能并等 IDLE，再批量设置，最后使能。启动超时1 s，校准有自身200 ms排队和锁定执行时长检查。

上电自动流程期间显示 STARTING，active_mode=USER_MODE_COUNT 表示尚未交接用户执行模式；完成后接管已有位置保持。用户显式关闭或选择其他模式可取消自动启动。

用户层关闭再使能只复位用户层状态，不清除控制器、驱动及其他底层故障。旧 g_speed_run/g_output_position/校准命令仍保留用于开发；用户使用新入口时不得混用旧命令接口，避免两个来源争用。

## RAM 与工程集成

加入全局对象和业务状态后，原先 RAM 接近满载。没有缩小2 KiB栈；将开发用位置轨迹记录从101点/400 ms间隔改为81点/500 ms间隔，保持40秒轨迹、位置更新频率和控制计算不变，回收320字节。位置轨迹主机测试相应调整为80个实际记录点。

Keil uvprojx 与 cproject.yml 加入 user_control.c。原生产 Flash 校准页仍为62/63，代码上限仍0x1F000。首轮完整编译0错误0警告；最终构建结果见文末追加记录。

## 验证

1. run_user_control_tests.ps1：六模式有效性、速度正反限值、不同加减速度、跨零反转；无编码器旋转电流连续20,000次；负电角频率、转矩反馈无效、使能关闭与模式切换门、NaN/Inf。
2. 同脚本编译真实 user_control_dispatch.inc：六模式启动/停止、上电取消、模式切换关闭边界、位置720°转换、校准参数锁定、完成态不重复启动、启动超时、底层故障保留。
3. run_calibration_tests.ps1：原有采集、持久化、CRC、撕裂记录、取消/超时测试；新增 D/Q 矢量偏角、负 Q-only 磁场零点补偿。
4. run_output_position_tests.ps1：原有协议/故障与轨迹回归；新增目标720/-180、正负跨零、累计720后返回-360，保留512计数跳变拒绝。
5. run_speed_tests.ps1：原有软件限流配置和真实硬件电流策略回归，增加D/Q校准执行与提交零点。原有 deferred outer PI 等价性测试保留。

这些是源代码和主机执行证据，不代表真实电机在所有模式、参数及负载下的控制性能验收。当前板卡仍运行此前固件；本次未用硬件结果替代软件验证。
