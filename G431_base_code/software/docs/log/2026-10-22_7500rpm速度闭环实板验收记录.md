# 7500 rpm 速度闭环交付 — 2026-10-22

最终固件已下载到本次 STM32G431VB 开发板；测试结束输出已关闭，上电不自动启动。

## 实板验收

- 7500 rpm 保持 30.45 s，17 次反馈快照均值 7500.73 rpm，范围 7489.48–7506.66 rpm。
- CRC、SPI 传输/启动、传感器报警、步长错误和新增 ADC 超期均为 0。
- 逐采样相电流峰值 4.978 A；ADC ISR 最大 46.679 us，周期 50 us。
- 7600 rpm 候选试验触发 6.039 A 逐采样保护；7800 rpm 旧候选峰值 7.511 A，均不合格。
- 因此最终指令上限 7500 rpm，0.50 pu 浅过调制，Iq 指令限幅仍 5 A。

修复：重新标定电角度零点 4.1586 rad；TIM16 将 SPI 采样移至 PWM 周期约 20 us；
启用 Flash 预取并优化 PI/调制路径；单次调制条件积分；新增自动测试心跳失联和逐采样
6 A 保护。普通未启用心跳的操作保留原有保护配置，不能假设也有新增 6 A 门槛。

## 复验

在原仓库根目录运行（先检查脚本中的 Python/GDB/pyOCD、DFP Pack 路径和探针序号）：

```powershell
python software/control_analysis/scripts/test_highspeed_closed_loop.py --image software/control_analysis/results/highspeed_7500_20261022/firmware.axf --tag my_readonly_check
```

默认只读，不启动电机。台架已固定、机械限速允许、现场具备断电条件后，加入 `--run`
才实际启动；默认从 500 rpm 分档递增。脚本拒绝超过 7500 rpm，不自动清故障或重试。
复现最终保持试验可另设 `--stages 7500 --dwell 30 --run`，固件仍从 0 按 300 rpm/s 升速。
自动测试使用锁存 8 s 心跳和逐采样 6 A 保护；主机异常退出仍请求 OFF 并检查 MOE。

解压包源码可从 `source/MDK-ARM/servo_v1.uvprojx` 用 Keil 6.24 + STM32G4xx DFP 2.2.0
构建。包中的脚本原本按仓库布局运行；若脱离仓库，需自行调整结果根目录/本机工具路径。

注意：速度是编码器反馈，不是独立转速表读数。该短时台架通过不等同于长期温升、带载
能力或机械额定转速认证。更换磁铁、编码器装配或相线后必须重新校准。
