## 3. “位置开环、电流闭环”在这里的确切含义

```text
Id_ref ──> 误差 ──> PI_d ──> Ud ─┐
                                ├─> 逆Park(theta=0) -> 调制/PWM -> 电机
Iq_ref ──> 误差 ──> PI_q ──> Uq ─┘                          │
             ↑                                              │
             └──── Id/Iq <── Park(theta=0) <── 两相电流 ADC ──┘
```

`theta=0` 时 Park 变换的旋转退化为恒等映射，D/Q 对应固定的 alpha/beta 坐标。编码器角度、速度 PI、位置 PI 均不参与该电流测试路径。

固定控制坐标系并不会锁住转子。定子磁场可能使转子对齐或运动；需要验证静止电气模型时，应使用可靠的固定转子工装和低能量激励。若固定轴与真实转子 D/Q 轴不重合，辨识出的电感是当前固定坐标系下的有效电感，不能直接宣称是电机铭牌 Ld/Lq。凸极电机、转子运动和轴间耦合显著时，单轴 R/L 模型不够，需要两输入两输出模型或转子定向测试。

## 4. 固件改动

### 4.1 固定电角度

在 `main.c` 的电流测试 ADC 路径中，每次处理时强制：

```c
current_open_loop.electrical_angle_rad = 0.0f;
current_open_loop.electrical_frequency_hz = 0.0f;
```

反馈组装时直接令 `input->electrical_angle_rad = 0.0f`，并移除了该模式下原有的虚拟角度积分。两个字段保留供 Watch 观察和结构兼容，但不再作为此模式的旋转命令。

原有电压开环模式仍是独立模式。本次固定角度约束针对 `FOC_CONTROL_MODE_CURRENT_OPEN_LOOP`。

### 4.2 PI 的数学定义和单位

实际执行顺序：

```text
e[k] = reference[k] - current[k]
I[k] = clamp(I[k-1] + Ki * dt[k] * e[k], Imin, Imax)
u[k] = Kp * e[k] + I[k]
```

因为本次误差先进入积分再计算输出，等周期线性模型为：

```text
C(z) = Kp + Ki*Ts/(1-z^-1)
```

这是后向欧拉积分形式。将 `pidtune` 默认的离散积分形式直接复制到固件可能不匹配，因此本次 MATLAB 显式构造上述控制器。

| 量 | 单位 |
| --- | --- |
| 电流和误差 | A |
| 电压命令 | pu，物理电压 / Vdc |
| Kp | pu/A |
| Ki | pu/(A*s) |
| 积分状态和积分限幅 | pu |
| dt | s |

固件 `Ki` 没有预乘 Ts；写参数时不能再乘一次或除一次采样周期。

### 4.3 参数应用入口

`g_current_tuning.apply_request` 的语义：

| 值 | 动作 |
| --- | --- |
| 0 | 无请求 |
| 1 | 使用已有 R/L 解析设计函数 |
| 2 | 使用本次新增的 `requested_d`、`requested_q` 独立 PI |

状态 `status=1` 表示已接受，`2` 表示运行中/模式不允许等忙条件，`3` 表示输入无效。参数仅在输出请求、armed、预充电、控制器运行和 MOE 均关闭时应用。实验已 armed 时也不接受增益变更。

直接应用时：

- 验证两轴 Kp/Ki 正数、有限值。
- 验证积分边界跨越 0 且不超过当前电压限幅。
- 验证 `design.dc_bus_v` 有限且为正。
- 将两轴积分历史清零。
- 将接受后的增益保存在 `g_current_tuning.gains`，用于重新进入电流 PI 阶段。
- 直接应用路径的解析带宽、解析裕度字段保持 0，**0 表示没有解析证书**；应使用 MATLAB 报告中的指标。

现有未知电机低增益投运值仍为 `Kp=0.005 pu/A`、`Ki=0.2 pu/(A*s)`。它们只用于原有低能量投运流程，不能声称为已测得的稳定参数或最佳参数。

### 4.4 数据捕获时基

原代码以 `ticks * 当前dt` 推算时间。当 dt 改变时，该算法会错置激励时刻。本次改为：

```text
elapsed += dt
```

每条缓存增加 `time_s`；`average_count=1` 时它代表当前记录相对于开始采集的累计时间。平均多个样本时记录块末时间，其他数据是块平均值，因此快速辨识必须使用 `average_count=1`。

缓存布局发生变化：新样本为序号、时间戳和六个 float 信号，共 32 字节；512 点为 16 KiB。旧的按 28 字节解析缓存的工具必须更新。它不改变串口现有帧协议。

## 7. “最优”的定义和算法

对象：

```text
G(s) = Vdc / (L*s + R)
```

先使用 ZOH 精确离散化，然后加入整数拍命令延迟。`extra_delay_s` 代表 **ZOH 以外** 的附加命令延迟，向上取整到采样拍数，默认示例为一拍。不能把已经包括 ZOH 的总等效延迟再原样叠加，否则重复计算。实际 ADC 窗口、计算和 PWM 生效时刻需要另行测量。

为了检查稳定性，离散延迟通过 `absorbDelay` 展开为状态，然后闭环。

搜索空间：

- 24 个对数间隔种子频率：30～800 Hz。
- Ki 比例系数：0.5、0.75、1、1.25、1.5。
- 起点 `Kp=L*2*pi*f/Vdc`，`Ki=R*2*pi*f/Vdc*系数`。
- 名义模型和 R/L ±20%、Vdc ±10%、附加延迟一拍/两拍的 16 个角点，总计 17 个模型。

角点筛选：闭环稳定，相位裕度至少 55°，增益裕度至少 6 dB，超调不超过 10%，2% 调节时间不超过 20 ms；0.05 A 单轴阶跃不得超过输出 0.02 pu、积分 0.01 pu 的边界。

候选目标函数取各模型最差值：

```text
ITAE / (阶跃幅值 * 仿真时长^2)
+ 0.001 * integral(u^2) / (输出限幅^2 * 仿真时长)
```

这是**指定有限网格、指定角点、指定测试幅值下的最佳可行候选**。不是数学全局最优，也不是对连续不确定参数区间的严格鲁棒稳定性证明。改变噪声、限幅、负载或指标，最优候选会改变。

非线性验证包括正负单轴阶跃对称性、正常阶跃与离散 LTI 模型等价性，以及 0.5 A 过载请求后回到 0.05 A 的恢复。MATLAB 的限幅仿真是单轴等效模型，未完整复制两轴同时激励时的电压圆、调制窗口、量化和测量噪声；这些需要后续固件/实机验证。

## 9. 实际电机的 R/L 如何获得

### 9.1 首先固定实验条件

记录电机编号、接法、母线实测电压、绕组温度、固定转子位置、电流标定版本、采样周期及电压命令生效时刻。测得的线间电阻不能在不确认接法时直接作为相电阻。低电阻测量还应扣除线缆、接触和仪器误差。

在 `theta=0` 下取得的有效轴电感可能随转子角度变化。若无法确定转子位置，至少在多个静止位置重复测量，使用保守参数范围；不能假设两轴相等。

### 9.2 开环电压到电流记录

使用现有 `D_VOLTAGE_CHECK` 阶段从零电压、小幅激励起步，记录实际施加的电压命令、对应电流和时间。限流、固定转子和方向检查沿用工程投运规程。

辨识 CSV：

```csv
time_s,u_pu,i_a
0.00000,0,0
0.00005,0,0
```

前 5% 记录应是稳定基线，之后有有效电压激励；每条输入代表从该时间起保持的命令。至少采集两次不同幅值/极性的实验。样本应连续、无饱和、时间近似等间隔；非均匀时基需要明确处理后再辨识，脚本会拒绝超过 1% 的时间间隔偏差。

```matlab
id = identify_current_rl('train.csv','validation.csv',24,'results/motor01_id');
```

`24` 必须替换成实测母线电压。模型参数换算：`R=Vdc/Kp_model`，`L=R*Tp1`。延迟、拟合百分比、验证图和残差图同时检查，不能只看一个拟合分数。

本次没有实现开环电压实验的自动高频导出。当前 512 点缓存入口只允许 DQ_PI 阶段；开环辨识数据需由另外的同步采集路径取得。现有 1 kHz 显示波形不能默认用于辨识 kHz 电流动态。用示波器/同步高速记录取得所需数据，或下一步扩展固件开环捕获。

这个辨识脚本只适用于上述开环实验。闭环中的电压命令与噪声可能相关，不能把闭环阶跃缓存直接当作该脚本的开环数据。

## 10. 固定零角度 D/Q 闭环的实机操作顺序

### 10.1 先停机并确认状态

烧录经审核的构建产物后，通过已有调试器 Watch 操作。以下是字段赋值顺序，不是已执行的实机记录。

1. 令 `g_global_mode_control.runtime.output_request=0`。
2. 等待 `output_armed=0`、`precharge_in_progress=0`、`g_foc_controller.running=0`，并确认 MOE 关闭。
3. 确认模式为 `FOC_CONTROL_MODE_CURRENT_OPEN_LOOP`。
4. 按已有投运流程完成小 Ud 方向检查，再选择 D 轴 P 检查；确认误差和控制方向。
5. 停机后令 `current_open_loop.requested_stage=FOC_CURRENT_STAGE_DQ_PI_CLOSED_LOOP`（枚举值 2），等待 `active_stage=2`。

默认上电阶段保留方向检查，没有自动跳过硬件方向验证；达到第 5 步后才是需要的 D/Q 电流 PI 闭环。

### 10.2 应用测量后得到的候选增益

在停机条件成立、测试未 armed 时，依次填写：

```text
g_current_tuning.design.dc_bus_v = 实测母线电压
g_current_tuning.requested_d.kp = result_d.Kp
g_current_tuning.requested_d.ki = result_d.Ki
g_current_tuning.requested_d.integral_min = -cfg.integral_limit_pu
g_current_tuning.requested_d.integral_max =  cfg.integral_limit_pu
g_current_tuning.requested_q.kp = result_q.Kp
g_current_tuning.requested_q.ki = result_q.Ki
g_current_tuning.requested_q.integral_min = -cfg.integral_limit_pu
g_current_tuning.requested_q.integral_max =  cfg.integral_limit_pu
g_current_tuning.apply_request = 2
```

等待请求清零，核对 `status=1`、`valid=1` 和 `g_foc_controller.algorithm.parameters.d_controller/q_controller` 的实际值。不要直接运行中修改 PI 多个字段。

### 10.3 采集一个全速 D 轴阶跃

停机后配置：

```text
g_current_loop_test.command = 3          // 回到 IDLE，等待执行
g_current_loop_test.requested.kind = 0  // STEP
g_current_loop_test.requested.axis = 0  // D，Q 测试则设 1
g_current_loop_test.requested.amplitude_a = 0.05
g_current_loop_test.requested.settle_s = 0.005
g_current_loop_test.requested.step_delay_s = 0.004
g_current_loop_test.requested.average_count = 1
g_current_loop_test.requested.capture_count = 512
g_current_loop_test.command = 1          // arm，等待 state=ARMED
g_global_mode_control.runtime.output_request = 1
```

0.05 A 是示例小信号幅值，实际值需匹配电机/电源限制。测试路径直接提供参考激励，绕过普通给定斜坡，以便测量环路响应。

512 点在名义 20 kHz 下覆盖约 25.6 ms；阶跃发生在约 9 ms，余下约 16.6 ms。若慢环尚未收敛，不能把最后一点当稳态；要延长捕获策略或缩短前置等待，不能用低采样率掩盖快速动态。

完成后固件冻结缓存并停止输出，正常为 `state=CURRENT_TEST_DONE`（3）。检查 `sample_count=512`、`abort_reason=0`、`saturation_count`。饱和数据用于评估大信号恢复，不能直接当作小信号性能证据。

### 10.4 导出缓存和分析

停止后从调试器导出 `samples[0 ... sample_count-1]`，保存为带表头 CSV：

