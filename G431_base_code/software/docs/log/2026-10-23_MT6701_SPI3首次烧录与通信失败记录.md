# 2026-10-23 MT6701 / SPI3 烧录实测

结论：烧录和回读校验成功，MT6701 通信验证未通过，尚无有效角度数据。

使用 ST-Link `E1007200D0D2139393740544`，SWD 500 kHz。
先读取 TIM1 BDTR 确认 MOE=0，再保存板上原固件 `previous_flash.bin`（完整 128 KiB）。
烧录本目录 `firmware.bin`（68,008 字节），逐字节回读全部一致后启动。
AXF、BIN、哈希与备份均保留在本目录，ABI 地址依据该 AXF 符号解析。

默认配置：PB6 软件 CSN、PB3 SPI3_SCK、PB4 SPI3_MISO，AF6，Mode 1，
256 分频，3 字节 / 24 个时钟，每 10 ms 调用一次。

固定 10 秒观察窗口的数据如下。首尾通过暂停测试任务并等待当前帧结束，
保存完整的 92 字节观测对象，避免读取到更新中的结构体。
两个最近采样时间戳相差 10,046 ms（含首尾暂停和 SWD 保存开销）。

| 计数增量 | 数量 |
| --- | ---: |
| 发起收发 | 1,000 |
| 有效帧 | 0 |
| HAL 收发错误 | 0 |
| CRC 错误 | 1,000 |
| 全零/全一帧 | 0 |

窗口末尾原始帧 `FF 9C 3F`，接收 CRC 为 `0x3F`，固件计算和电脑独立复算均为
`0x01`，不匹配。有效角度字段保持初始值，不能把其 0 度读数当作测量结果。

附加排查：

- 暂停测试后修改 SPI3 CR1，Mode 0/1/2/3 各观察约 150 帧。
  Mode 0/1 为 CRC 错误，Mode 2/3 为全一帧，均无有效帧，见 `mode_0.log` 至 `mode_3.log`。
- 通过 SWD 临时将相同引脚改为 GPIO，完成一帧慢速采样；数据为全零。
  此采样速度受 SWD 影响，不作为正常 SSI 时序验证证据。结束后恢复 GPIO 复用和 SPI3 配置。
- 全程未请求电机运动。实测 TIM1 MOE=0，`output_request=0`、`output_armed=0`、
  `g_speed_run.enable=0`。原始寄存器记录见 `interval.log`。

最终状态：测试固件运行，恢复默认 Mode 1，周期测试启用，电机功率输出关闭。
没有通过改 CRC 参数或放宽有效帧判定来接受错误帧。

下一步需要实物核对 MT6701 供电、共地、MODE 电平与 CSN/CLK/DO 接线，
并在芯片侧采集 PB6/PB3/PB4 对应信号的逻辑分析仪波形，判断片选、时钟边沿和数据是否匹配。
目前证据不足以定位到某根连线或芯片故障。

完整计数和原始对象见 `verification.json`；原始快照见 `interval_before.bin` / `interval_after.bin`。
