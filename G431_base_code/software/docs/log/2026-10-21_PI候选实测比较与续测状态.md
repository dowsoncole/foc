# 2026-10-21 PI 候选实测比较与续测状态

> 后续勘误（2026-10-21 恢复供电后）：独立 DWT 计时发现旧固件控制中断超时，2048 次更新实际约 205 ms，并非文中假设的 102.3 ms。因此下文及旧比较图的时间轴、IAE、响应时间不能作为真实 20 kHz 的评价依据；平均值和标准差仍是当次记录的统计量，但不能与新固件混排。本文保留历史原貌。最新证据见《2026-10-21_控制周期修复与重新整定日志.md》。

## 当前结论

整理了上一轮已完成的 12 次 MCU 内部缓存测试。Kp=0.0025、Ki=1.6 在已测的正向 0.05 A 阶跃中，D/Q 综合跟踪误差最小，是下一轮复测候选，不是已经验证的全工况最优值。

稳态波动尚未解决。候选参数主要消除了约 100 ms 观察范围内的欠跟踪；末段采集波动没有在两轴都明显下降。因此没有修改源码中的默认 Kp=0.005、Ki=0.2，也没有把调试器 RAM 中的临时参数描述成重启后保留的参数。

## 测试方法及指标解释

- 固定电角度 0，20 kHz 电流环，ADC profile 5（12.5 周期、16 倍硬件过采样）。
- 每次只给一个轴 0→0.05 A 阶跃，另一轴给定零；两轴使用相同候选增益。
- 阶跃前等待 10 ms；每 4 次控制周期平均保存一点，保存 512 点，合计约 102.3 ms。
- 末段统计取最后 128 个记录点，即约 25.6 ms；误差为末段平均反馈减给定。
- IAE 为整段绝对跟踪误差积分，含前 10 ms 的零给定阶段，数值越小越好。
- 标准差是四点平均后的反馈波动，不是全速原始电流纹波，不能直接与此前无平均噪声记录比较。
- Kp 单位 pu/A，Ki 单位 pu/(A·s)，软件每周期执行积分 I+=Ki×error×Ts。不是每周期离散 Ki。
- 相电流关断阈值 0.25 A、输出电压矢量限幅 0.02 pu、积分限幅 ±0.01 pu。

每次记录均完整、序号连续，测试完成后固件自动关闭输出。日志中的参数申请状态为 1，回读参数吻合。未出现采样窗口拒绝、写入截止时间拒绝、实测相电流保护、采集饱和计数。上述事实仅覆盖这些短测试。
