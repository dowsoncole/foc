# 3 A bounded encoder-alignment diagnostic image

This is a diagnostic candidate, not a validated maximum-speed release.

- Static Id alignment limit: 3 A, slew 1.5 A/s; hardware trials use 5 s.
- Original 20 rad/s alignment trip, CRC, freshness and deadline checks retained.
- No automatic motor startup, no sensor EEPROM writes.
- AXF/HEX/BIN: 64112 matching Flash-load bytes, including RW initialization.
- Boot profile is the historical 5.3988 rad value; the later speed test explicitly
  used a measured 4.02575541 rad RAM profile. Do not confuse those profiles.
- `../secured_cal3a_i2t_staged_20261023/summary.json`: 8200 rpm held 6.109 s;
  next 8400-rpm stage stopped on CRC at frozen feedback 8336.654 rpm.
- Same-field 3 A zero changed by 78.291 electrical degrees across that run.
  Positive/negative full electrical turns differed by only 3.757 degrees.
  Stable calibration is not established; the cause needs further investigation.
- Final output is OFF and RAM calibration invalidated, but reset removes that
  RAM-only inhibit. I2t trial remains consumed; recorded heat is 82.564453125 A^2*s.
  Any later changed-image I2t trial must carry at least 82.565 A^2*s; no cooling
  has been measured or credited.
