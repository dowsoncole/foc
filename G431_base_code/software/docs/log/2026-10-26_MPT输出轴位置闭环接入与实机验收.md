# MPT 输出轴编码器与位置环接入（2026-10-26）

## 当前完成情况

- USART1：PA9 TX、PA10 RX、PA8 高发送/低接收，2,500,000 baud，8N1。
- MBS-15-32-A-17M-T-N-C-M 使用 T485；依据本仓库 MPT 数据手册 PDF 第 15–16 页（印刷页码 14–15），不是普通 R485 指令表。
- 发送 `0x1A`，接收 11 字节：命令、状态、角度低/中/高字节、标识、多圈低/中/高字节、告警、异或 CRC。角度 17 位，131072 counts/rev。B5 实机读回 `0x11`（十进制17），原始帧保留供诊断。
- 位置环与输出轴读取统一为 200 Hz（5 ms）；`OUTPUT_POSITION_PERIOD_MS` 同时控制二者。电机速度环仍为 1 kHz，期间保持位置环的速度给定。后台快速调用只是推进 DMA 接收状态，不会额外发起读请求。
- 关闭旧 SPI3 临时测试入口：它会在10 ms轮询时抢占 PB3/PB4/PB6，与正式 SPI1 SSI 后端冲突。
- RX 使用 DMA1 Channel3；SPI1/MT6701 保持原来的 DMA1 Channel1/2。USART1 波形发送在 OUTPUT_AXIS_ENABLE=1 时停用。
- 已实现输出轴位置 P 环 → 电机速度给定 → 原 MT6701 速度 PI 环 → 原电流环。减速比固定 202。位置误差不作最短路径折返；例如 359° 到 1°按负方向走 358°。
- ARM AC6 6.24 编译通过（1 succeeded / 0 failed）；主机测试通过。已下载并核对 Flash。首次静止通讯实测超过 6.3 万帧，五类通讯错误均为 0；后续闭环实测结果见下文。

当前默认 `OUTPUT_AXIS_ENABLE=1`，上电自动执行原有 1.5 V / 3 秒电角度校准，随后自动进入当前位置保持；不启动原 500 rpm 速度给定。针对本机已验证的安装方向，默认 `commissioned=1`、`motor_direction=+1`。等待 `g_output_position.state==1` 且 `g_speed_run.state==2` 后，只修改 `target_deg` 即可定位。初始化会把目标设为当前位置，启动前写入的目标会被覆盖。停止/故障后不会自动重启。

## 先验证通讯

1. 连接调试器和控制板。确认停机，构建/下载本次 AXF；不要混用旧 `MDK-ARM/servo_v1/servo_v1.axf` 符号。
2. 当前构建产物为 `software/control_analysis/build_mpt/out/servo_v1/servo_v1/servo_v1.axf`。
3. 观察 `g_mpt_t485`：`initialized=1`，`good_frames` 持续增加，连续 10 帧正确后 `valid=1`；`crc_errors/format_errors/status_errors/timeouts/uart_errors` 不再增加。
4. `frame[0..10]` 保存原始帧。角度为 `angle_raw*360/131072`；静止时应稳定，受控改变输出轴角度时应连续变化。
5. 只读验证脚本（不下载、不复位、不启动电机、不写编码器）：

```powershell
python software/control_analysis/scripts/verify_mpt_communication.py --image software/control_analysis/build_mpt/out/servo_v1/servo_v1/servo_v1.axf
```

脚本先确认输出关闭、核对整段 Flash 与 AXF，再采集通讯计数和原始帧，保存 `software/control_analysis/results/mpt_comm_时间/summary.json`。静止通讯通过不代表方向和闭环精度已验证。

收发时序：RX DMA1 Channel3 先就绪，PA8 拉高后至少等待 1 us，再发送一个命令字节。新增 TIM7 单脉冲定时器 + DMA1 Channel4 自动向 GPIOA BSRR 写复位位；按 USART 实际 BRR 和外设时钟计算 10 bit 完整帧时间，再加 16 个定时器时钟作为保持余量。CPU 不再关中断等待线传输，只有 TDR/CEN 两个相邻启动写操作位于短临界区。接收按完整 11 字节检查，避免提前使能 RX 后的旧 IDLE 标志截断响应。位置计算放在后台，速度 ISR 仅取保持的速度给定。

响应超过 2 ms 未完成记超时；位置环按请求时间判断反馈年龄，超过 17 ms（3 个位置周期 + 2 ms）停机。TIM7 和 DMA1 Channel4 由此驱动独占。实机复查 FOC 截止时间/ADC 采样窗口计数；尚未用示波器测量物理时序。

## 再验证并启用位置环

1. 先完成以上通讯验证和原有 MT6701 电角度校准，确保 `g_speed_test.calibration_ok=1`。速度模块需回到 idle（state=0），所有故障均已排查；本模块不会自动清除电机故障。
2. 通过已有有界低速测试实测方向：正电机速度使输出角度增加则 `g_output_position.motor_direction=1`，反之为 `-1`。没有假定安装方向。
3. 确认 PWM 下通讯及控制截止时间正常后，才设置 `g_output_position.commissioned=1`。此变量是调试门控，不是软件自动得出的实测结论。
4. 在输出关闭状态写 `g_output_position.command=1`。模块锁存增益和方向，把目标设为当前角度，再请求已有速度环的启动流程。它仍受驱动器、电流采样、MT6701 和电机模式联锁约束。
5. 观察 `state=1` 且 `g_speed_run.state=2`，再改变 `target_deg`；先使用远离两端的小角度阶跃。默认 `kp_per_s=2.0`，电机速度限幅 `max_motor_rpm=2500`，位置死区 `deadband_deg=0.01`。增益、限速、方向、死区在 arm 时锁存，运行中修改这些字段不生效；须停机后重新 arm。
6. 任意时刻 `command=2` 停止。位置故障后保持锁存，输出关闭时 `command=3` 仅清位置模块故障；其他故障须单独处理，然后重新 arm。

位置给定范围为 0..360°；保持运行期间使用相邻单圈角度展开，因此可以识别 359.99°→360°，继续越界则故障。0°与360°物理角度相同，掉电后不能仅凭单圈绝对值区分两端；本型号普通多圈数据也不提供掉电保留。当前坐标使用编码器原始零点，尚未建立机械回零/零偏保存；若机械端点与编码器零点不同，应先定义机械坐标再进行全行程测试。此软件范围检查不能代替机械行程保护或消除停机惯性。

`g_output_position` 调试字段：

| 字段 | 含义 |
|---|---|
| state | 0 停止，1 位置控制，2 故障锁存 |
| fault | 1 反馈无效/过期，2 电机环停止/故障或门控撤销，3 参数/范围无效，4 编码器角度跳变，5 启动被拒绝 |
| target_deg / actual_deg / error_deg | 输出轴目标、展开位置、误差，单位度 |
| motor_rpm | 位置环计算的电机速度给定；其后仍经过原速度环的斜率限制 |
| updates | 约 200 Hz 位置环更新计数 |

## 当前位置模式：结构体用法

结构：输出轴位置 P + 轨迹速度前馈（200 Hz）→ 电机速度给定/斜坡（1 kHz）→ 原 MT6701 速度 PI → 原电流环/PWM（10 kHz）。位置反馈使用 MPT 输出轴编码器，每 5 ms 仅发起一次读取。

`motor_rpm = motor_direction * (kp_per_s * position_error + velocity_deg_s) * 202 / 6`，结果限幅到 `max_motor_rpm`。死区内位置 P 项为 0；运动前馈仍有效。位置模式电机速度斜坡为 2000 rpm/s，独立速度模式保留原 300 rpm/s。它们是速度/加速度限制，不是电流限制。

`g_output_position`（类型 `output_position_t`，56 字节）：

| 字段 | 默认值 / 读写方式 | 用法 |
|---|---|---|
| command | 0，可写 | 写 1：在当前实际位置启动保持；写 2：停止；写 3：停机时清除位置故障。命令被消费后归零。 |
| state | 0，只读 | 0 停止，1 位置环激活，2 故障。还需检查 `g_speed_run.state==2` 确认内环运行。 |
| fault | 0，只读 | 1 反馈失效/超时；2 内环故障/停止；3 参数或角度越界；4 反馈跳变；5 拒绝启动；6 轨迹参数、跟踪误差或主动中止。 |
| commissioned | 1，停机配置 | 本机编码器方向及通讯已验证。改硬件安装后应重新验证；0 禁止启动并撤销运行。 |
| motor_direction | +1，停机配置 | 电机正转使输出编码器增加。仅可取 ±1，启动时锁存。 |
| target_deg | arm 时设为当前位置，可实时写 | 输出轴绝对角度，0..360°；固定点控制直接写此字段。不是电机角度。 |
| actual_deg | 只读 | MPT 输出轴展开角度，单位 °。 |
| error_deg | 只读 | `target_deg - actual_deg`。 |
| motor_rpm | 只读 | 位置环输出的电机转速命令，经过限速；实际速度见 `g_speed_run.actual_rpm`。 |
| kp_per_s | 2.0，停机配置 | 位置比例增益，单位 1/s，合法范围 (0,10]，启动时锁存。 |
| max_motor_rpm | 2500，停机配置 | 电机转速命令绝对值上限，合法范围 (0,2500]，启动时锁存。 |
| deadband_deg | 0.01，停机配置 | 位置误差死区，合法范围 [0,1]°，启动时锁存。 |
| updates | 只读 | 位置计算次数，正常约 200 次/秒。 |
| velocity_deg_s | 0，可实时写 | 输出轴速度前馈，单位 °/s，范围 ±75。固定目标必须设为 0。轨迹测试时由单片机更新。 |

默认上电会自动完成以下校准、清理校准完成状态、启动位置保持流程。正常使用只需等待就绪，然后修改目标。以下手动顺序供主动停止后的重新启动使用（不能用阻塞等待阻塞后台编码器服务）：

1. 保持输出 OFF，确认两编码器、驱动及采样正常。
2. `g_speed_test.requested.kind=10; g_speed_test.command=1;` 执行既有 1.5 V、3 秒电角度校准。等待 `calibration_ok==1` 且 `state==3`，再写 `g_speed_test.command=3`，等待 `state==0`。
3. 设置位置参数（默认已适配本机），写 `g_output_position.command=1`。
4. 等待 `g_output_position.state==1` 和 `g_speed_run.state==2`，再写目标，例如：

```c
g_output_position.velocity_deg_s = 0.0f;
g_output_position.target_deg = 180.0f; /* 输出轴绝对 180° */
/* 停止： */
g_output_position.command = 2U;
```

重新启动前，速度测试模块也必须回到 idle；正常停止后可在 OFF 写 `g_speed_test.command=3`。故障后先查明原因，本模块不自动清除其他模块故障。位置模式已默认选用，上电自动校准并保持当前位置；不会自动运行 ±90° 轨迹。

## 0.1 Hz 正弦试验结构体

`g_output_position_test` 是可选的有界测试，不影响日常固定点控制。位置模式保持且静止后，设置 `amplitude_deg=90`，再写 `command=1`。以当前位置为中心，10 秒五次多项式平滑移到负端点，随后 20 秒执行两个 0.1 Hz 余弦周期，最后 10 秒平滑返回中心。±90° 指相对中心，不是向有界角度接口写 -90°。

- `command`：1 开始，2 中止并停机；自动消费归零。
- `state`：0 空闲、1 正在运行、2 完成并保持中心、3 失败/停止。
- `fault`：错误原因；同时查看位置模块的 fault。
- `amplitude_deg`：可配置 (0,90]°，启动时锁存；频率固定 0.1 Hz。
- `center_deg / elapsed_s`：只读，试验中心和已运行秒数。
- `peak_error_deg / squared_error / samples`：200 Hz 统计的峰值绝对误差、误差平方和、样本数，RMS=`sqrt(squared_error/samples)`。
- `trace_count`：记录数；`g_output_position_trace[]` 每 400 ms 保存时间、目标、实际角度和电机速度命令，共最多 101 条。

中心 ±幅值必须落在 5..355°，启动前误差小于 0.1°且速度命令小于 5 rpm；运行误差超过 10°或越过轨迹范围 2°则停机。40 秒后轨迹自动完成，外部脚本另保留心跳超时停机。主机脚本为 `software/control_analysis/scripts/test_mpt_position_sine.py --run`，先做 Flash 身份校验，再按 ±10°、±45°、±90°逐级执行。

## 当前电流和时钟策略

按用户要求，`FOC/Inc/current_policy.h` 默认 `CURRENT_LIMIT_HARDWARE_ONLY=1`，所有模式的相电流幅值跳闸、速度 PI 的 Iq 限幅、FOC 的 d/q 矢量限幅、电流测试幅值限制及 I²t 停机均关闭。`current_limit_a` 活动参数统一为 `FLT_MAX`，历史电流阈值不生效；实际限流由硬件负责。NaN/Inf、驱动故障、编码器、超速、行程、心跳、PWM 和电压约束保留。电压 PI 的饱和抗积分累积不是电流限幅。

主频目标始终为 168 MHz。先尝试 HSE 12 MHz（M=3/N=84/R=2）；若 HSE 启动失败则回退 HSI 16 MHz（M=4/N=84/R=2）。`g_system_clock_source=1` 表示 HSE，`=2` 表示 HSI 回退。该字段必须用于确认实际时钟来源，不能把回退运行宣称为外部晶振验证成功。
