## 5. 当前架构核对结果

| 项目 | 当前源码结论 | 主要依据（相对 servo_v1） |
| --- | --- | --- |
| 程序形态 | 裸机：前台低速任务 + 中断实时控制 | `Core/Src/main.c`、`stm32g4xx_it.c` |
| 系统时钟 | 先 HSE 12 MHz PLL 至 168 MHz，失败尝试 HSI PLL | `main.c` 的 `SystemClock_Config()` |
| 电流/PWM频率 | 10 kHz，100 µs，ARR 8400 | `Core/Inc/control_timing.h` |
| 默认启动 | 电压对齐 1.5 V / 3 s，提交电角度零位后进入输出轴位置保持 | `main.c`、`Servo/Src/speed_commission.c` |
| MOE | 启动初期关闭；自举预充及随后运行会使能 | `main.c`、`Modules/Three_Phase_Driver/Src/tim1_pwm.c` |
| 电机编码器 | MT6701 SPI1 + DMA，14 位角度；SPI3 仅试验分支 | `Modules/Encoder/Src/spi1_encoder.c`、`mt6701_ssi.c` |
| SPI时序 | 谷值启动；24 位 / 1.3125 MHz 约 18.29 µs；DMA 完成后解析并发布快照 | `stm32g4xx_it.c`、`encoder.c` |
| ADC时序 | TIM1 CH4 / TRGO2 触发；两相完整序列约 1.190 µs，规划值 1.192 µs | `adc1_current_sampling.h`、`pwm_sampling.c` |
| 数据交接 | 控制器内部回调取快照和给定，再进入电流算法；FOC不等待SPI | `foc_interface.c`、`main.c` |
| 外环 | ADC链内速度环约1ms；前台输出轴位置环至少5ms | `speed_commission.c`、`output_position.c` |
| 输出轴反馈 | MPT T485 RS-485，由前台轮询DMA接收并解析 | `Modules/Encoder/Src/mpt_t485.c` |
| 抢占关系 | TIM1/SPI DMA优先级0，ADC优先级1；可抢占FOC | `stm32g4xx_hal_msp.c`、`spi1_encoder.c` |
| 探针含义 | PA0/PD2是通信/CRC错误锁存，不是当前FOC/SPI运行窗口 | `Core/Inc/timing_probes.h` |
| 电流策略 | `CURRENT_LIMIT_HARDWARE_ONLY=1`，不把关闭的软件幅值约束写成有效保护 | `FOC/Inc/current_policy.h` |

这些是代码静态核对结果。当前板上实际时钟源、传感器内部延迟、ISR 最坏耗时、PWM 提交余量与高速性能未在本次重新测量。旧日志可作为历史证据，但不能证明当前固件通过相同工况。
