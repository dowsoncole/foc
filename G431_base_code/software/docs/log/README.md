# 开发调试日志

返回[架构说明](../架构说明.md)。本目录保存开发过程与历史证据，不作为当前参数或功能已验收的依据。

## 记录规则

- 命名：`YYYY-MM-DD_主题与结论.md`；跨日记录注明日期范围，同日记录用主题区分。不能确认日期的旧记录保留“未注明日期”，不按文件修改时间猜测。
- 详细记录：目标与背景、代码版本、板卡和接线、编译配置、工具版本、复现步骤、参数变更、命令、观测值、成功及失败结果、结论边界、下一步。未知项明确写“未记录/未验证”。
- 区分证据：源码推导、主机测试、仿真、烧录成功、实板运行、逻辑分析仪实测分别写明；不能相互替代。
- 结论更新：保留原始失败过程，在后面追加复核或更正；设计方案、待办和候选方案不冒充已实现或已通过验收。
- 归档原则：历史正文保留，只补来源标记和修正链接。图片、CSV、JSON、固件、构建记录与源码快照保留原位置，通过链接关联。
- 当前用户说明包括[架构说明](../架构说明.md)、[位置环调试与使用说明](../位置环调试与使用说明.md)、[编码器结构体与软件分层说明](../编码器结构体与软件分层说明.md)和[电流校准说明](../电流校准说明.md)；修改启动、频率、通信、控制路径、类型职责或电流换算时同步更新对应说明。
