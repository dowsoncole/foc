# 2026-10-27 U 相物理电流标定

## 1. 目的和结论

示波器 CH4 的电流钳夹在电机 U 相。本次以 CH4 的安培读数为物理基准，校正 ADC 原始码到程序安培值的比例，使 FOC、用户电流指令和状态反馈使用的 A 与实物相电流一致。

静态标定后又按用户要求增加了电机旋转时的开环电流标定。最终写入程序的参数：

| 参数 | 标定前 | 标定后 |
| --- | ---: | ---: |
| U/V 分流电阻 | 7 mΩ | 7 mΩ，未修改 |
| 等效板级增益 | U/V 均按 6.1 | U=16.89535；V=17.53506 |
| 单次采样电流比例 | U/V 均为 0.01887262 A/count | U=0.00681389；V=0.00656530 A/count |
| U/V 软件极性 | -1 / -1 | -1 / -1，未修改 |

最终旋转复核：0.50 A 指令在 2 Hz、5 Hz 下的 U 相基波峰值分别为 0.49254 A、0.49323 A，误差为 -1.49%、-1.35%；编码器均值约 59.07 rpm、150.01 rpm，证明电机实际旋转并基本跟随 2 对极理论转速。0.30 A / 1 Hz 点基波为 0.28694 A，低 4.35%，低电流点受 10 mA 量化和 PWM 残差影响更明显，未用于继续追调。

标定时 TCP0030A 的箭头与程序正方向相反，因此原始 CH4 显示与程序读数异号。程序正方向定义为“电流从逆变器流入电机 U 相端”。没有为迎合钳子安装方向而翻转软件极性；如需示波器同号，应把电流钳反向安装。

## 3. 零电流基线

功率输出关闭时，CH4 采集 1,000,000 点，时间间隔 400 ns，总窗口 400 ms：

| 指标 | CH4 |
| --- | ---: |
| 平均值 | +0.000067 A |
| 交流 RMS（标准差） | 0.010470 A |
| 最小值 | -0.030 A |
| 最大值 | +0.050 A |
| 1% / 99% 分位 | -0.010 A / +0.030 A |

零电流均值接近 0，说明主要问题不是电流钳零偏。MCU 每次上电仍独立采集约 1 ms 的 ADC 零偏；本次只标定安培比例，没有用固定偏置替代上电零偏采集。

## 4. 标定前五点实测

标定前代码使用 6.1 倍增益，即 0.01887262 A/count。CH4 的原始符号与程序约定相反：

| 程序 Id 指令 / A | CH4 均值 / A | CH4 标准差 / A |
| ---: | ---: | ---: |
| -1.00 | +0.329711 | 0.045219 |
| -0.50 | +0.160299 | 0.024745 |
| +0.25 | -0.091635 | 0.019396 |
| +0.50 | -0.192544 | 0.030737 |
| +1.00 | -0.385993 | 0.052542 |

最小二乘结果为：

```text
CH4_A = -0.35530433 × program_A - 0.01826724 A
R² = 0.99857577
```

斜率负号来自电流钳箭头方向。斜率绝对值说明旧程序把物理电流放大显示约 2.81 倍。由第一轮斜率得到初始修正值 0.00670552 A/count，等效增益 17.1684。

## 5. 第一轮修正后的闭环复核和二次修正

第一轮修正下载后，重新测量四个正负点。下表“物理 U 相”已把 CH4 符号换算到程序正方向：

| 程序指令 / A | CH4 均值 / A | 物理 U 相 / A |
| ---: | ---: | ---: |
| -0.50 | +0.496309 | -0.496309 |
| -0.25 | +0.235308 | -0.235308 |
| +0.25 | -0.273447 | +0.273447 |
| +0.50 | -0.523890 | +0.523890 |

四点拟合：

```text
physical_A = 1.019661312 × command_A + 0.016429760 A
R² = 0.99995600
```

同一固件在零电流指令且 MOE 打开时，CH4 均值为 -0.008020 A，标准差 0.006415 A。该结果不支持人为改写上电零偏；因此只用拟合斜率做第二次比例修正，把等效增益从 17.1684 调整为 16.83736，对应 0.00683735 A/count。

## 7. 静态阶段代码修改

修改文件：`software/servo_v1/Modules/Current_Sampling/Src/current_sampling.c`。

- 新增统一常数 `CURRENT_SAMPLING_EFFECTIVE_GAIN=16.83736f`。
- `CURRENT_SAMPLING_A_PER_COUNT` 使用该常数计算，热路径仍是预计算常数乘法，没有增加 ISR 浮点除法。
- `g_current_sampling.opamp_gain` 和板级参数加载检查使用同一个常数，避免元数据与实际换算不一致。
- 保持 `polarity_u=-1`、`polarity_v=-1`；这两个值属于控制坐标定义，不能根据电流钳朝向随意翻转。

因为安培比例发生变化，旧固件日志中仅由 ADC 换算得到的电流数值不能继续当作当前物理电流，也不能简单改写历史记录。保护门槛、PI 参数和较大电流运行表现应基于新比例重新评估；本次没有宣称完成全转速和全电流范围重新验收。

## 9. 旋转标定方法

静态标定只让电角度停在 0，此时主要验证 U 相通道。旋转标定继续使用 `USER_MODE_OPEN_CURRENT`，但令 `electrical_hz` 为 1/2/5 Hz，使 D 轴电流向量连续旋转：

```text
Id = 0.3 或 0.5 A
Iq = 0 A
electrical_hz = 1 / 2 / 5 Hz
```

FOC 不使用编码器角度，编码器仍发布实际 rpm 作为独立运动证据。2 对极电机的同步机械转速为 `30 × electrical_hz` rpm。

示波器每点采集至少 4 个电周期，对 CH4 波形按已知频率拟合：

```text
Iu(t) = offset + a*sin(2*pi*f*t) + b*cos(2*pi*f*t)
fundamental_peak = sqrt(a*a + b*b)
```

同时通过非停机 SWD 读取 100 组 `status.actual_rpm/id_a/iq_a`。MCU 未在 MOE 打开时暂停。波形保存在 `software/control_analysis/results/current_calibration_rotating_20261027/`。

新增的复现工具：

- `software/control_analysis/scripts/capture_rotating_phase_current.py`：控制 MDO34、保存 CH4 波形、拟合基波，结束后恢复示波器设置；频率填 0 时用于静态均值采集。
- `software/control_analysis/scripts/sample_open_current_status.py`：非停机读取 MCU 转速、Id/Iq 统计，不修改控制命令。

## 11. U/V 分相比例推导

静态 U 相阶段关系为：

```text
physical_U = 0.99656778 * software_U + 0.00661197 A
```

忽略小截距，U 通道软件/物理比例约 `1/0.99656778 = 1.003444`。对幅值平衡的旋转三相电流，U/V 增益接近时，旋转坐标 D 轴直流增益近似为两个相通道增益的平均值。由 2/5 Hz 的 MCU Id 均值与 CH4 U 相基波得到动态平均增益 1.023003、1.021879，均值 1.022441，因此推得 V 通道软件/物理比例约：

```text
sV = 2 * 1.022441 - 1.003444 = 1.041438
```

把原公共增益分别乘以 U/V 修正量，得到首轮分相候选：

```text
gain_U = 16.83736 * 1.003444 = 16.89535
gain_V = 16.83736 * 1.041438 = 17.53506
```

对应比例为 U=0.00681389 A/count，V=0.00656530 A/count。V 值属于由 U 相静态计量和旋转平衡关系推导的间接标定；本次没有把电流钳移到 V 相直接测量。
