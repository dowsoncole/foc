# 程序执行流程简述

本文按当前 `servo_v1` 正常固件说明。程序是裸机运行：主循环负责启动、模式切换和后台任务；中断负责按固定节拍采集与控制。测试宏启用时，执行路径可能不同。

## 上电到运行

1. `main()` 初始化时钟、GPIO、TIM1、ADC、运放、SPI/通信和驱动监控；先保持 PWM 输出关闭（MOE=0）。
2. ADC 采样链启动后，等待模拟电路稳定约 20 ms，再采集约 1 ms 的零电流数据，计算 U/V 相电流零偏。校准失败则不继续启动。
3. 启动电机编码器采集，并从 Flash 尝试加载已保存的电角度零点。默认自动启动时：没有有效零点就先做一次编码器对齐并保存；有有效零点则跳过对齐。
4. 反馈和驱动状态就绪后，默认进入输出轴位置保持。用户也可通过 `g_user_control` 的 `mode`、参数和 `enable` 选择电压、校准、电流、转矩、速度或位置模式。使能及故障检查通过后才开启功率输出。
5. 运行期间，主循环持续处理用户命令、输出轴位置反馈、驱动监控、编码器状态和故障；关闭使能或出现故障时撤去输出。

## 运行时一个控制周期

TIM1 每 **50 µs** 给出一个 PWM 周期边界：更新中断发起电机编码器的 SPI DMA 通信；DMA 收完后解析并发布最新角度/速度。TIM1 还在合适的 PWM 时刻用硬件触发 U/V 相 ADC 采样。ADC 序列完成后进入中断，读取电流和编码器反馈，执行 FOC，并把新三相 PWM 比较值写入定时器预装载寄存器；新值在后续周期边界生效。FOC 不等待 SPI 通信完成，而是读取当时最新的有效快照。

速度环约每 **1 ms** 在低优先级 `PendSV` 中计算电流给定；位置环和输出轴 MPT T485 通信在主循环中服务。

```text
TIM1 周期边界 → SPI DMA 读取电机角度 → DMA 完成、解析并更新反馈
        └────→ 硬件触发 ADC → ADC 中断：电流反馈 → FOC → 写 PWM 预装载
主循环：用户命令 / 输出轴位置环 / 故障与驱动管理
PendSV：速度环 → 下一批 FOC 周期使用的 Iq 给定
```

## 主要函数的作用

| 函数                               | 简单作用                                              |
| ---------------------------------- | ----------------------------------------------------- |
| `main()`                         | 上电初始化，完成电流校准，并持续运行后台服务。        |
| `MainUser_Service()`             | 读取 `g_user_control`，处理模式、使能、停机和状态。 |
| `ServoManager_Service()`         | 在正常控制模式下管理输出使能与故障状态。              |
| `OutputPosition_Service()`       | 处理输出轴位置反馈和位置环，给出电机速度目标。        |
| `MptT485_Task()`                 | 处理减速器输出轴编码器通信。                          |
| `Encoder_OnPwmPeriodIsr()`       | 在 TIM1 周期边界启动电机编码器 SPI 采集。             |
| `Encoder_TransferComplete()`     | SPI DMA 完成后解析帧并更新编码器反馈。                |
| `MainFoc_OnAdcConversion()`      | ADC 采样完成后的实时控制入口。                        |
| `SpeedCommission_OuterService()` | 在 PendSV 中更新速度环电流给定。                      |
| `FOC_ControllerStep()`           | 读取电流、角度和给定，计算控制输出并提交 PWM。        |
| `DrvMonitor_Task()`              | 在主循环中检查栅极驱动器状态和心跳。                  |

主要源码位于 [`main.c`](../servo_v1/Core/Src/main.c)、[`stm32g4xx_it.c`](../servo_v1/Core/Src/stm32g4xx_it.c)、[`speed_commission.c`](../servo_v1/Servo/Src/speed_commission.c)；
